# 示例简历编写硬规则（Resume Guidelines Example）

> 提示：本文件为示例参考模板。请复制一份为 `resumeGuidelines.md` 并根据个人偏好微调（`resumeGuidelines.md` 已被 `.gitignore` 忽略，绝不会被推送到 GitHub）。

## 核心原则

1. **绝对防编造（Fact First）**：未在真实经历中做过的事情一律不写，经不起深挖的亮点宁可舍弃。
2. **量化须有对比基线**：出现“提升 30%”等数字时，必须说明前置状态或因果链，否则标记为待核实。
3. **中英双语同源**：英文简历不是中文的胡乱机翻，必须基于同一套事实底座输出。
4. **拒绝空洞表述**：严禁出现“参与相关工作”、“熟悉常见框架”等无信息量套话。
