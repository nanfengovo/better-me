# 示例求职目标与边界红线（Career Objectives Example）

> 提示：本文件为示例参考模板。请复制一份为 `careerObjectives.md` 并填入你自己的真实求职目标（`careerObjectives.md` 已被 `.gitignore` 忽略，绝不会被推送到 GitHub）。

## 1. 核心定位

- **主标签**：高级全栈/后端工程师 · 工业系统架构
- **副标签**：分布式系统 · AI 工程化落地
- **工作地点**：上海 / 远程

## 2. 薪资与级别目标

- **薪资底线**：20K–28K / 月（14–16 薪）
- **期望职级**：高级工程师 / 技术专家 (Senior / Lead)

## 3. 筛选约束（红线原则 · 绝不妥协）

- [x] **0 出差**：核心研发岗，拒绝长期驻场技术支持与设备现场调试。
- [x] **0 Oncall / 健康工时**：拒绝无意义 996 与常态化夜间救火。
- [x] **外企 / 优质产品型团队**：拒绝低毛利、人盯人的纯外包交付项目。
