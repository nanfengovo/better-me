# 简历模板库

当前 Web 预览已实现三套自研布局，统一消费同一份 `ProjectedResume`，切换模板不改写事实内容：

| ID | 排版与场景 | 来源 |
|----|------|------|
| `zh-classic` | 居中姓名抬头、正式分节、可选照片，适合中文正式投递 | 自研 |
| `en-ats` | 纯单栏文字顺序、可见链接、无照片与装饰侧栏，适合简洁投递 | 自研 |
| `clean-modern` | 分区信息抬头、优势标签与经历强调线，可选照片 | 自研 |

布局位于 `apps/web/src/components/ResumeTemplate.tsx`，样式位于 `apps/web/src/index.css`。三套模板均支持当前中文/英文字段输出；模板名称不触发自动翻译。照片开关用于经典/现代预览及打印，ATS 模板始终无照片。预览支持缩放和横纵向滚动；打印忽略预览缩放，按 A4 自然跨页，不强行裁成一页。

PDF 通过浏览器打印/保存为 PDF；Markdown 复制与下载是共享的内容导出，不包含模板样式。DOCX、独立模板 manifest/缩略图、`zh-sidebar` 与额外模板尚未由本目录提供。ATS 是简洁排版方向，不承诺所有招聘系统的解析或筛选结果。

本轮没有移植外部主题、字体或图片，也未替项目选择开源许可证。之后若适配开源模板，须逐个核实代码、文档及资产的许可，并随模板保留上游 LICENSE/NOTICE。**禁止**爬取或镜像商业简历网站模板。
