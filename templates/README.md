# 简历模板库

BetterMe 的自研与第三方适配模板统一消费 `ProjectedResume`，用于真实缩略图、实时 A4 纸面和浏览器 PDF。完整可选清单见 [CATALOG.md](CATALOG.md)，机器可读元数据见 [catalog.json](catalog.json)。这两份目录由实际注册表生成；目录中的主题均具有实际样式实现，来源清单中的链接不自动等于已集成主题。

当前模板分为 BetterMe 自研、RenderCV、JSON Resume、NewFuture 与开源社区。第三方源包括单栏、日期轨、章节侧标、资料侧轨、卡片、多栏、RTL 及原项目真实配色/项目变体。名称、描述、建议配色/字体、上游链接和许可来源均集中在注册表；当前数量与分组以生成目录为准，不在本文维护另一套手工数字。

## 使用与功能边界

切换模板只更新所选版式 ID，不改写 Fact，不自动更换用户已经设置的主题色、字体、字号、间距或页边距。需要原版建议色与字体时，使用界面的显式推荐样式操作。中文/英文输出取已有双语字段，与界面语言独立；选择英文名称的主题不触发自动翻译。模板不为凑版式生成学校、论文、技能分数、政治面貌或考试成绩。

正式预览和图库使用同一 React 渲染组件。图库仅使用固定双语合成示例，保持实际 A4 比例，不读取私人 Fact，也不生成正式预览锚点或嵌套链接。用户照片继续遵守显示开关；`en-ats` 固定无照片。上游主题中缺乏当前事实模型支持的评分表、兴趣、引用或专门的报考表格不会被伪造；对应差异见模板说明及逐源 NOTICE。

预览可缩放和滚动；连续纸张不是逐页排版编辑器。PDF 使用浏览器打印，忽略屏幕缩放，按用户所选 A4 边距自然跨页，不强制压缩或裁成一页。Markdown 是内容导出，不携带这些视觉样式；DOCX 保持可编辑单栏正文，不承诺与当前 PDF 或上游模板同版。RenderCV YAML 是结构化出口，不意味着网站安装或执行了 RenderCV 引擎。ATS 名称仅描述简洁排版方向，不是解析通过或招聘筛选的认证。

## 源码与维护

- [注册表](../apps/web/src/components/template-catalog.ts)：实际模板 ID、分组、中英文说明、推荐参数、来源和许可元数据。
- [共享纸面](../apps/web/src/components/ResumeTemplate.tsx)：Fact 投影后的呈现、稳定预览锚点、文字格式和显示控制。
- [纸面基础样式](../apps/web/src/components/resume-paper.css) 与 [独立适配目录](../apps/web/src/components/templates/)：按模板 ID 限定 CSS，避免污染工作台和其他模板。
- [完整目录](CATALOG.md) / [JSON 清单](catalog.json)：从上述实际注册表生成，保留来源、许可/NOTICE、推荐参数及原生适配范围。
- [许可证与修改说明](licenses/)：逐源完整 LICENSE、NOTICE，必要时保留原始 package 元数据、源文件许可和固定 revision。
- [源码审计记录](../docs/reports/sources/)：JSON Resume 官网快照覆盖、RenderCV 内置主题、NewFuture 三种打印样式，以及 awesome 全部 31 个顶层入口的可用与排除依据。

接入新主题时，先读真正控制布局的源文件，再核对该文件自身、包/仓库和字体/图片等资产的许可。适配进入实际注册表前，应具备真实样式、中文/英文合成缩略图、稳定锚点和长文本 PDF 验收；不能只增加名称、链接或共用空壳。固定上游 commit 或包版本/归档校验信息写入 NOTICE。**禁止**爬取或镜像商业简历站模板。
