# BetterMe v1.2.0

本版重点是「按需训练工坊」：从一个具体学习困难出发，由本机模型设计练习，组合交互或编写受限计算逻辑，再由宿主验证和保存。英语只是其中一个例子，不把模块限制成固定英语课程。

## 本次更新

- 新增「学习提升 → 训练工坊」，并在「资料与练习」提供同一入口。支持目标与具体困难输入、可纠正的模型假设、先确认方向再构建、不需要应用时只给建议，以及注明非 AI 生成的零模型示例。
- 新主题可由模型组合情境、书写、策略选择与自评，例如练习向非技术同事解释概念。开放式练习只检查参与情况，不把自评或完成填写当作专业能力评分。
- 英文邮件精简和并行项目排期可由模型编写纯 JavaScript 计算程序。代码只在受限 QuickJS worker 内执行，宿主用独立样例和实际输入复查，失败不能冒充通过；最多允许一次针对完整失败结果的修复。
- 工具临时试用与持久保留分开；按账号保存不可变版本、原始作答及是否先看过提示。首次提交满 24 小时后开放另一情境；重开、练习和复测不重复调用模型。跨窗口更新和新旧题目绑定均有防误提交校验。
- 本机 Ollama 路径固定 loopback 和本机专用请求，校验协议、模型来源与摘要，无云模型回退、静默下载或不明确结果自动重试。无需云端 API Key。
- 累积包含 v1.1.0 以来已合入的履历盘点、分步文本写作、离线听写、资料练习、岗位采集与三维地图改进、双语工作区、桌面交互及本机桥接安全修复。各功能仍遵循自己的依赖和授权条件，不因为本版发布自动认证历史未验业务场景。
- README 更新使用路径、模型前提、持久化与费用边界；保留四平台原生打包、成品启动烟测、完整安装包集合与 SHA-256 发布门禁。

## 安装和更新

按系统与处理器选择附件：macOS arm64 / x64 各提供 DMG 和 ZIP，Windows x64 为安装 EXE，Linux x64 为 AppImage。核对相应 `SHA256SUMS-*`；更新前建议导出重要资料的 JSON 备份，不要删除原用户数据目录。没有自动更新器，也不会自动迁移浏览器、开发环境与独立发行包之间的资料。

macOS 使用 ad-hoc 签名，尚未提供 Developer ID 公证；Windows 尚无 Authenticode 发布者证书。请遵循操作系统提供的人工确认流程，不要全局关闭系统防护。Linux 原生依赖要求 glibc ≥ 2.34，不代表兼容所有发行版。

## 训练工坊的模型与能力边界

- 安装包不附带 Ollama 或模型权重。用户需自行安装、启动并选定本机标签；工坊当前只放行已审计的 Ollama 0.40.15 / 0.40.16，本机验收使用 `gemma4:e2b-it-qat`。未知版本或来源会明确失败，不猜测为安全。
- 开放式工具通常两次本机调用；计算工具最多四次。保留后练习无需重新推理。这里没有按次云模型费用，但有本机算力、电力和自行准备依赖的成本。
- 只将本人填写的目标与具体困难用于本次诊断和构建，不自动读取职业资料；保留的目标、工具和作答存入当前账号的本机学习库，账号隔离不等于磁盘加密或跨设备同步。
- 没有新增实时语音、麦克风许可、任意脚本安装、shell、联网或本机文件权限。邮件仅核对指定词和词数；排期仅验算给定图；开放式练习不认证专业正确性或长期掌握。
- 网页与原生 Electron 的生成、保存、换题、重启恢复已经使用临时合成账号与真实本机模型验证；跨平台打包和烟测不替代各平台全部人工业务验收。

更多实现与复验说明见 [按需训练工坊报告](https://github.com/nanfengovo/better-me/blob/v1.2.0/docs/reports/personal-training-workshop-2026-11-17.md)。
