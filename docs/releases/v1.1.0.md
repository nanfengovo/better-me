# BetterMe v1.1.0

BetterMe 以“可信职业工作台 + 个人职业 Agent”为定位，职业资料与业务版本由 Workspace 管理，Agent 围绕明确目标和授权执行任务。

## 本次更新

- 新的非字母化“资产之核”图标，统一网页入口和桌面安装包。
- macOS arm64 / x64 的 DMG 与 ZIP、Windows x64 安装程序、Linux x64 AppImage。
- 包含页面、Electron 运行时和本地后台依赖；不要求用户安装 Node、pnpm 或 Docker。
- 独立的桌面运行入口、稳定的 loopback 地址、私有运行目录与自有进程清理。
- 更新 Electron 稳定版本，启用 renderer sandbox、context isolation、导航和 IPC 边界。
- 配套 SDK 与 Worker 的 PDF 兼容性修复，以及桌面窗口与 CI 回归修复。
- 四组原生打包烟测、平台 SHA-256 和发布前完整性校验；README 更新为实际产品边界与安装说明。

## 安装与更新

选择与系统和处理器相匹配的附件，并核对 `SHA256SUMS-*`。更新前先导出重要资料的 JSON 备份，保留原应用数据目录。

macOS 使用 ad-hoc 签名，尚无 Developer ID 公证；Windows 暂无 Authenticode 发布者证书。系统可能提示未知开发者，不要通过全局关闭安全保护来安装。当前不提供自动更新器。

桌面本机地址为 `127.0.0.1:32741`；端口冲突会阻止启动，不接管其他服务。浏览器、旧开发环境和新桌面会话之间不自动迁移资料，请显式导出和导入。

## 能力边界

云模型、本机 Ollama、原生 CLI、招聘浏览器与 vork 需要各自的安装或授权条件。AI 请求会将授权资料发送到选定服务商；本地优先不等于所有功能完全离线。烟测验证打包后的启动、界面挂载、后台健康和退出清理，不替代所有平台的完整人工业务验收。
