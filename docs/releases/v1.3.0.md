# BetterMe v1.3.0

本版聚焦 **Calm Craft OS 设计系统重构**、**全局可配置快捷键与撤销/重做栈**，以及 **官方招聘源发现与后台寻岗**：让本地职业工作台拥有表里如一的桌面级手感与可控的寻岗闭环。

## What's New / 本次更新

### 1. Calm Craft OS 设计系统与简历工作室重构
- **可复用设计原语层**（`apps/web/src/design-system/`）：沉淀 `Button`（6 级语义变体 × 4 档尺寸 × 顶部高光与按压回弹）、`SegmentedControl`、`SelectMenu`（支持分组与完整 WAI-ARIA 键盘导航）、`SplitButton`、`StatusPill` 与 `useSortableList` 丝滑拖拽原语，并附带独立单元测试。
- **简历工作室体验升级**：
  - 消除顶部双下拉箭头与冗余边框噪音，明确全页唯一的 Primary 视觉焦点（「导出 ▾」分裂按钮）。
  - 左侧经历列表支持基于 Pointer Events 的 60fps 丝滑拖拽排序（附键盘 `↑ / ↓` 排序）与本地化语义徽标（`工作 / 项目 / 教育`）。
  - 要点输入框升级为自适应内容高度（Auto-Grow）与聚焦浮现富文本工具条，释放大量垂直写作空间。
  - 默认折叠「导入原文与待补录」为单行信号条，并过滤个人信息行避免补录误判。

### 2. 全局快捷键引擎 & 文档级撤销/重做
- **内置 12 项主流跨平台快捷键**：`⌘/Ctrl + Z` 撤销修改、`⇧ ⌘ Z / Ctrl + Y` 重做修改、`⌘/Ctrl + S` 立即保存、`⇧ ⌘ S` 历史版本、`⇧ ⌘ F` 专注模式、`⇧ ⌘ D` 内容/设计切换、`⌘/Ctrl + K` 按简历找岗位、`⌘/Ctrl + ,` 系统设置、`⌥/Alt + 1~4` 切换工作台。
- **系统设置 → 快捷键**：新增实体键帽交互面板，点击任意键帽按下新组合键即可实时录制、自动检测冲突并全局生效，支持单项与一键恢复默认。
- **文档级撤销/重做栈**：覆盖文本编辑、增删经历/要点、拖拽排序与模板切换，连续打字 400ms 内智能合并。

### 3. 官方招聘源发现、后台寻岗与安全加固
- **多平台官方招聘源适配**：新增 Workday、Eightfold PCS、Workable、SmartRecruiters 等官方招聘搜索与证据发现链路，串联简历定向寻岗弹窗与后台寻岗监控（`job-service`）。
- **本机命令行调用加固**：将 macOS `osascript` 与 `lsof` 调用全面改为参数化 `execFile` / `execFileSync` 并限定 `-sTCP:LISTEN`。
- **修复窗口层级问题**：确保「系统设置」窗口在主窗口铺满状态下仍可正常置顶弹出。

## 安装与校验 / Downloads & Verification

选择与操作系统匹配的安装包并核对对应的 `SHA256SUMS-*` 文件：

- **macOS (Apple Silicon / arm64)**: `BetterMe-1.3.0-macos-arm64.dmg` / `.zip`
- **macOS (Intel / x64)**: `BetterMe-1.3.0-macos-x64.dmg` / `.zip`
- **Windows (x64)**: `BetterMe-1.3.0-windows-x64-setup.exe`
- **Linux (x64)**: `BetterMe-1.3.0-linux-x64.AppImage` (glibc ≥ 2.34)

> macOS 发行包采用 ad-hoc 签名，Windows 尚无 Authenticode 商业证书，首次运行请遵循操作系统的人工确认流程。升级前建议先在应用内导出 JSON 备份。
