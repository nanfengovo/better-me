# 首次使用工作台引导

引导直接挂在主应用 `App.tsx`，不是 UI Lab 或独立示例页。首次进入内容编辑器、数据加载结束且没有其他弹窗时，等待 650ms 后展示。若用户已在字段中输入，本次页面会保持安静；之后仍可从顶部头像「工作台设置 → 新手引导」主动开启。工作台总览和 Agent 协作场景共用 `SpotlightGuide`：同一套真实界面聚光、沉浸卡片、键盘和动效机制；总览认识区域，协作场景逐步讲清具体入口，不再在侧栏内堆八宫格目录和长教程。

## 交互

1. 欢迎：浮动简历、三维轨道、粒子、扫描光与柔和极光。
2. 真实经历：聚光实际编辑区，说明场景、行动和结果。
3. 主动伴写：高亮实际伴写工具栏，区分本地提醒、模型授权与改写确认。
4. 预览与导出：高亮实际模板和导出区。
5. 草稿保护：高亮保存控件，强调当前浏览器与 JSON 备份。
6. 你的 Agent：高亮顶部 AI Agent 入口，介绍统一侧栏、任务连续性和问号帮助。
7. 探索机会：高亮岗位地图导航，不启动采集或第三方登录。
8. 准备就绪：庆祝粒子与返回编辑器。

每步可前后切换、跳过单步或直接点击进度。右上角关闭或 Esc 跳过整个引导；完成或跳过后不会自动重播。左右方向键切换步骤，输入框内保留正常编辑按键；原生模态 dialog 管理背景不可交互与焦点约束，关闭后恢复焦点。窄屏优先使用控件上方或下方的空间，短横屏在控件旁收窄卡片，长内容内部滚动；找不到可见锚点时明确说明前置条件。

## 动效与安全边界

- 无新运行依赖，使用 CSS 的 transform/opacity 和可中断的 Web Animations API；复用工作台已有缓动令牌。
- 开场和收尾使用较丰富的轨道、浮动纸张、扫描和粒子；功能步骤使用聚光边框、光点和进度流光。
- 「沉浸动效」随时可关闭；系统 `prefers-reduced-motion: reduce` 优先，停止循环及位移动效，保留静态说明。键盘切换不播放卡片入场动画。
- 仅写入 `betterme:onboarding:v1`，内容为版本与 `completed` / `skipped` 状态，不包含简历、模型配置或令牌。存储被禁用或写满时允许关闭并直白提示无法记住偏好。
- 不调用简历更新、保存、导入、重置、模型或岗位采集接口；完成引导不创建历史版本。跨标签页完成/跳过会关闭同源的其他引导。
- 偏好与浏览器 Origin 绑定；换端口、换浏览器或清站点数据后可能再次出现，这是首次使用偏好而非云端账号设置。

## 验证

运行 `pnpm exec tsx --test apps/web/tests/first-run-guide.test.tsx` 检查偏好版本、损坏/禁用存储、定位边界、首次弹出、输入/弹窗保护、跳过/重播/完成、键盘导航、动效开关与跨标签页关闭。实际 Docker 工作台还需验证原生焦点、所有锚点、小屏和系统减少动态效果；DOM 单测不等于真实浏览器性能验收。

运行 `pnpm exec tsx --test apps/web/tests/first-run-guide-theme.test.ts` 用独立的本机 Chromium 加载实际引导与主题 CSS，覆盖四套工作台配色的浅深模式。全屏引导及其原生 `::backdrop` 必须保持透明，仅由 SVG 绘制带挖空区域的遮罩；通用弹窗主题规则不得覆盖它，否则聚光区会变成空白色块。测试同时确认普通原生弹窗与 `role="dialog"` 弹层仍正常使用主题表面色。

设计参考了 [Driver.js 的产品引导/聚光模式](https://github.com/nilbuild/driver.js)，未复制源码或引入依赖。弹层沿用项目原生 dialog，语义与行为依据 [MDN dialog 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)。

## Agent 协作场景引导

从统一 Agent 侧栏的问号打开，默认继续上次章节；旁批、资料授权和贡献线索中的帮助按钮可直达相关章节。工作台总览的伴写、Agent、结束步骤可直接交接，先关闭总览再打开协作引导，不叠两个模态。进入章节只准备相应的伴写、记忆或工具视图，实际工作组件始终挂载并可见于聚光后方。

| 章节 | 安全练习 | 真实入口定位 |
| --- | --- | --- |
| 资料授权 | 在必要说明和整盘授权之间选择 | 当前经历 → 项目理解 → 资料范围 |
| 动态对话 | 选项不符时自由补充，不必硬选 | 项目理解输入框 |
| 核对共识 | 区分项目能力与本人贡献 | 当前版本理解卡片 |
| 认领贡献 | 区分实际实现、仅设计、其他人完成 | 贡献线索与个人确认 |
| 旁批候选 | 原文/虚线/旁批示意，打开候选并撤销 | 当前旁批与本人补充 |
| 历史与备份 | 不将同网址误认为自动云同步 | 记忆保存、备份与恢复 |
| 模型与工具 | 额度不足时停止，而非自动切付费 API | 受控阅读工具，推理模型独立选择 |
| 超时恢复 | 先核对状态，避免重复发送 | 共识与进度 → 任务 |

- 每次只展示当前场景、真实入口提示、前后切换与进度条。「用示例了解这一步」默认收起，按需展开三步说明、边界和安全练习。练习是固定教学示例，不连接模型、不读文件、不改变个人资料或正式任务；这不限制正式 Agent 的动态问题、选项或对话轮数。
- 「已看」和「已练习」分别记录；仅翻页不会勾选练习完成，不用教程进度伪装任务进度。可跳过练习、按章节跳转、随时退出或重播。
- 翻页只切换视图并滚动显示真实锚点；优先定位输入、来源按钮、标题或选择框，而不是框住整个滚动侧栏。点「找到入口」关闭模态，交给非模态定位教练；「重新定位」仅滚动和聚焦，不点击、不展开授权、不代替确认、不调用模型。可返回本节，原始旁批高亮和连线不改动。
- 共享聚光框按滚动祖先和视口裁剪；隐藏控件跳过，控件出现/折叠或滚动后重新测量。缺少控件时如实说明前置步骤，已有旁批或理解卡片时不错误提示为空。实操中切换其他 Tab 暂停教练定位。
- 协作卡片内部滚动，底部进度、上一步/下一步、跳过和减少动效选项保持可用。窄屏按可用空间限制高度，短横屏按控件旁可用宽度收窄，避免卡片覆盖所讲解的控件。
- 卡片复用总览的 250ms 可中断淡入/轻位移，实际工作内容不参与动画。键盘操作、关闭动效、隐藏侧栏和系统减少动态效果取消运动；示例输入框的左右键只移动光标。退出还原教程入口焦点。

### 进度存储和恢复

独立键 `betterme.agent-tutorial.v1:<workspaceKey>` 只保存 `version/current/viewed/practiced` 四项，值仅为章节 ID；不存示例输入、简历、授权、对话、凭据、模型或自动保存设置。刷新后可继续章节和已完成的练习；示例输入只是当页练习，不作为正式草稿备份。

损坏或未知版本按新进度处理，未知章节过滤；禁用存储或额度写满时显示「仅在本页保留」，仍可练习和退出。真实 Agent 记录保持原有浏览器/服务端存储边界，教程不重新发送、取消、恢复或重建任务。
