# 机会地图参考与统计口径

日期：2026-10-16。参考：[MVP Global](https://mvp-global-pi.vercel.app/)。

## 本轮实际观察

通过普通公开 HTTP 请求获得首页 HTML，HTTP 200，页面标题是 `MVP Global — A world of expertise`，说明是全球 Microsoft Most Valuable Professionals 社区探索目录。首页公开文字含 `3,830` 位 MVP、`105` 个国家/地区；导航有 Explore、Directory、About，入口含总量说明与加载中的 atlas 容器。

这些数字是参考站该次 HTML 的社区人数/国家范围，不能用于 BetterMe 的岗位数量示例，也不能解释为招聘市场数据。

尝试通过内置浏览器阅读交互时，浏览器返回用户拒绝该访问权限；因此停止所有对该网站的进一步打开、截图和交互验证，没有换浏览器或终端绕过拒绝继续读取页面。上述 HTML 在拒绝之前已取得。本轮没有证实具体的旋转、点击、筛选、下钻和悬浮行为；方案中的这些能力是 BetterMe 的设计建议。

未获得参考站源码或代码/设计许可。可借鉴信息组织思路，不能称作“已接入该项目”或直接复制其未授权资产。

## BetterMe 首版建议

同一查询结果驱动指标摘要、二维地图、岗位列表和侧栏。早期用个人收藏及少量平台真实样本验证；正式数据以公司招聘官网和 LinkedIn、51job、BOSS、猎聘等原始招聘平台为主，开源聚合作补充。中国/世界视图共享模型，国内/海外与远程/现场分别筛选。

地图需要表达岗位办公地点、远程可工作地区和公司总部三种不同概念；首版只将确认的工作地点作为岗位地图点。地图库、瓦片/地理数据、中文地址归一化与 WGS84/国内坐标处理独立选型。

## 本轮补充确认：切换、主源与逐条溯源

国内/海外切换后，地图范围与聚合、数量摘要、岗位列表、地区筛选和来源覆盖同步变化。保留适用的技术栈/级别筛选；处理不兼容城市条件时明确告知。工作地点决定现场/混合岗位的市场归属，公司的资本来源、总部和平台所属国家不能代替实际工作地点。远程另存允许工作地区。

平移/缩放默认只改变视野与聚合；显式开启“仅看当前地图范围”后才将视野作为筛选，并同步列表/数量。学习计划引用岗位/JD 的具体版本；源更新不自动覆盖已接受计划。

每张岗位卡展示公司、职位、地点、来源平台、可点击原文、披露的发布时间、岗位状态和最近核验信息；详情中展开完整来源链和各类时间。无披露信息明确缺失，不补造日期。

| 来源/时间字段 | 含义与显示规则 |
|---|---|
| 原始详情平台与 URL | 实际取得职位正文的平台，允许跳回原文；企业官网和招聘平台分别标识 |
| 发现渠道与 URL | 最初线索渠道，例如开源仓库，不能在跳到官网后丢弃其来源链 |
| 发布主体与认证 | 企业/猎头或中介/未知；平台认证与官网交叉核验独立记录，不由 AI 自动授予 |
| 原始发布时间 | 来源明确披露的发布时间；仅相对日期时保留原文与观察时点，估计时间必须标注 |
| 源更新时间/刷新时间 | 来源披露的变更或刷新，不能当首次发布；HR 活跃时间也不当岗位时间 |
| 首次发现时间 | 本系统第一次看到岗位的时间，不能当首次发布时间 |
| 本次采集时间 | 本次取得快照的时间，源发布很早也不能因此伪装成新职位 |
| 最近核验时间 | 最近检查开放/关闭状态的时间与核验方法；不能称作已获雇主确认 |
| 岗位状态 | 开放、关闭、无法确认等，保留来源证据；请求失败不能直接判岗位已关闭 |

官网与平台数据冲突时保留每份来源观察及其时间，显示冲突和摘要采用依据，不静默拼接成不存在的岗位。公司/批次级开源入口先归为线索，补齐真正职位详情后才进入完整职位去重统计与 JD 分析。

## 计数契约

| 指标/情形 | 规则 |
|---|---|
| 职位数 | 唯一 canonical job，附当前状态和筛选范围 |
| 公司数 | 归一化 company ID，名称不同不直接视作不同公司 |
| 招聘人数 | 仅原文明确披露才统计；职位条目数不换算成人数 |
| 多地点职位 | 全球唯一计一条；每城市可出现，城市和可能大于全球唯一数，界面解释 |
| 跨来源重复 | 关联同一个职位及多条 SourceObservation，保留证据和合并原因 |
| 同标题不同岗 | 结合官网编号/部门/级别等确认，不能只用公司和标题粗合并 |
| 远程 | 单列允许地区/时区和限制，不随意放到总部坐标 |
| 地点未知 | 进入未知地点桶，不显示为某地区零岗位 |
| 来源未覆盖 | 与已覆盖但无结果区分，地图灰色/说明不表示当地无市场 |
| 失效/历史 | 与当前开放职位分开；状态/更新时间不明确时明确标识 |
| 趋势 | 仅在可比较历史快照与覆盖范围内计算，不能用单次抓取称增长 |

## 能力验收

可从任意地图聚合数字打开同范围列表，并复算唯一岗位数；多来源重复只计一次；一个多城市职位不污染全局计数；一条只允许加拿大工作的远程岗位不会被标为全球远程；来源失败不会伪装为岗位骤降；没有地点的信息不会被放到公司总部。

以上是设计和未来测试案例，本轮没有实现地图或获取全量招聘数据。
