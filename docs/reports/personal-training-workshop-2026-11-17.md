# 学习提升：按需训练工坊

BetterMe 的学习模块可以把一次具体的困难转成可重复使用的小应用。入口在「学习提升 → 训练工坊」；「资料与练习 → 按需训练工坊」使用同一套组件、账号与工具架。

## 怎样体验

1. 输入一个目标和一个真实遇到的困难；已有确认目标也可主动点「带入」，它只填输入框。系统不扫描简历、工作记录或文件。
2. 点「同意并分析难点」。本机模型提出待核对的假设；信息不足时会请你举例，一次建议就够时不创建应用。
3. 认可方向后，再点「认可方向，构建试用版」。也可直接选下方注明“非 AI 生成”的内置示例，体验交互而不调用模型。
4. 试做后可「保留此版本」。初次提交满 24 小时开放另一情境；试算过与未先看反馈的作答分开记录。保留、重开、换题、试算和提交都不会重新调用模型。确认舍弃只删除所选版本及本版作答。

| 生成方式 | 例子 | 可验证与不可验证的内容 |
| --- | --- | --- |
| 按需组合界面 | 「我给非技术同事解释缓存时一直在堆术语」→ 模型创作两个情境，每题自由组合 2–4 步书写、选择或自评。这不是写死的“缓存课”。 | 只核对哪些栏目有效填写；自评不是客观分数，工坊不能认证专业正确性。 |
| 模型编写计算逻辑 | 压缩一封工作邮件，保留行动与日期。模型给出两封素材和要求，编写英文词数计算程序。 | 宿主复查词数与指定词；不评语法、语义、礼貌程度或真实英语水平。 |
| 模型编写模拟器 | 并行任务延期后，先预测交付天数，再用滑块试算，换一张依赖图复测。 | 宿主从任务依赖独立计算工期；不代表真实项目的交付保证。 |

## 运行与边界

- 诊断与创作走本机已安装的 Ollama 模型。每次诊断一次推理；开放式工具再一次设计，计算工具另需设计与代码，只有收到完整候选且未通过独立验收才允许一次修复。未知调用结果不自动重发，不下载模型、访问云模型或读取 API Key。
- 固定 loopback、禁止重定向和环境代理，发送学习内容前检查模型权重来源、摘要与 Ollama 本机协议；请求使用严格的 `:local` 名称，回复后重新核对它们。工坊明确支持已审计的 0.40.15 / 0.40.16；不把未知版本猜为安全，也不放宽旧编码实验台。参见 [Ollama 上游两版代码差异](https://github.com/ollama/ollama/compare/v0.40.15...v0.40.16)。
- 模型描述界面与数据，不给前端下发 HTML、脚本、第三方组件或插件。需要计算时，JS 只在受限 QuickJS worker 内处理一个有界 JSON 输入，不能获得文件、网络、麦克风、密钥、Node 或桌面 IPC。模型不能决定自己的验收用例。开放式练习走声明式组合，不为表单生成不必要的程序。
- 试用在当前账号会话内有效，最长两小时。只有显式保留才在该账号学习库落盘工具内容、目标/困难和本版作答。不跨账号显示、不自动成为职业事实或简历；本地账号隔离不是磁盘加密。请求编号单独存储，防止断线/重启后重放模型调用。
- 控件的操作说明由宿主负责，模型不能把数字预测框改成问答题。公开样例可反馈给模型；隐藏和用户题不向模型公开参考答案。每次作答都独立复查；校验不一致不记为学习成果。

## 如何复验（使用隔离夹具）

在仓库根执行，不指向正式 Host 或用户资料目录：

```sh
# 一次生成与复测（参数分别可选 rewrite、dependency、canvas）
pnpm exec tsx --tsconfig apps/web/tsconfig.json apps/agent-host/scripts/verify-training-kits.ts --synthetic-local gemma4:e2b-it-qat canvas

# 启动独立的 5336 夹具；另开一个终端跑下面其中一条。
pnpm --filter @better-me/web exec node --import tsx node_modules/vite/bin/vite.js --config tests/ui-lab/learning-path.config.ts --configLoader native
node apps/desktop/tests/training-kit-acceptance.cjs --isolated
node apps/desktop/tests/training-kit-acceptance.cjs --isolated --real-local
```

双端脚本需要已构建的桌面 preload 和已安装的 Playwright Chromium。同一种模式重复运行时重建临时夹具，以免测试工具架留下同名版本。新业务能力应区分“演练参与”与“有独立参考答案的计算”，并配套权限、数据边界、迁移题与验收；不要赋予模型任意设备权限来模拟新能力。
