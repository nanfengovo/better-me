# 履历盘点：从一份旧稿走到本人的选材策略

2026-11-14，现有 `agent-os` 工作区。本片只改变产品能力，不把任何个人偏好写进项目资料，不改变个人简历或岗位。以下例子全部为合成材料。

## 用户路径

导入完成后选择「一起盘点最近的变化」，或「直接进入编辑」。已有简历可在简历工作室顶栏点「盘点履历」。打开、刷新和退出都不因盘点自动推理或改稿。早期文档若缺稳定标识，会明确提示如何通过备份、恢复建立标识，不默默迁移。

1. **现在与底稿。** 分别问“底稿内容大约写到什么时候”和“从那以后你在做什么”。文件日期只是线索；答“不确定”或跳过均可。
2. **倒序经历。** 可连续补多件旧稿外材料，并区分雇主任职、独立作品、学习及其他。旧稿中最近的工作/项目在先，作品链接和未解析行单独核对，最后到教育。原文和本人口述分开；跳过不等于这段没有价值。
3. **工作偏好。** 从具体情景问协作方式、喜欢与不喜欢的工作/氛围、红线和未来方向。选材、岗位提醒、规划可分别授权。
4. **共识与选材。** 共识卡初始不勾选，可修正原话、逐项选择或全选，再单独确认。输出重点、压缩、不选、待补及下一步；明确偏好的材料原词只对同为“重点”的材料排序，并给出理由，不推断能力。替换同主题偏好或撤回后，下一次建议以当前允许的内容为准。

例：“业余做了事件回放器”保留为独立作品；“只设计了重试流程，没有做生产上线”只属于对应经历。进入逐条精修，只有对应经历出现引用入口；引用仅填入本轮补充，不能自动发送或采纳。“不能长期驻场”与岗位“要求长期驻场”提示可能冲突；“无须长期驻场”显示原句需核对，没提驻场则建议面试时问。不会因此修改匹配分或断言公司文化。

## 保存和授权边界

- 账号私有的 Host 记录保存盘点草稿、已确认陈述、选材回执和当前偏好；正式文档、对外简历和普通 JSON 备份不包含这些新记录。未勾选回答仍可存在于本人的草稿，不写入当次画像或选材回执。撤回影响后续使用，不是删除历史回执。
- 回执绑定账号、文档、简历视图和材料指纹；服务检查命令版本、复核摘要和画像版本。相同命令的即时重试不重复确认；不同窗口或底稿发生变化时要重新核对。保存的是本人原话，不是第三方认证。
- 文字主流程不用模型。可另点「请模型追问」查看目的地和将发送的问题、当前回答，再批准一次。共用 Agent Task Kernel 的当前运行时和根预算，不给工具、不读整份盘点、不自动重试或更换模型。只有用户回答能进入本人陈述，模型的问题不能。
- 第一版为文字输入；同日的[按住说话续片](career-inventory-dictation-2026-11-14.md)增加本机普通话输入，没有扩大原保存或发给模型的授权。不自动生成面试或学习计划、不自动改稿。JD 使用本人指定的原词做本地提醒，不是语义测评；未用真实外部强模型做质量或成本对照。
