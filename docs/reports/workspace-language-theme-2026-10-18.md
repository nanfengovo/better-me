# 全局界面语言、主题与简历输出独立 · 2026-10-18

用户希望最外层一键切换整个工作台的中英文及明暗，同时保留简历自身中英输出。本轮已完成实现和独立页面实际验收，未提交或推送。

## 交付行为

| 入口 | 影响范围 | 保存位置与独立性 |
| --- | --- | --- |
| 顶栏「界面 中文 / EN」 | 导航、工作区、编辑标签、模板介绍、版本差异及设置/导入/岗位弹窗的界面文案 | 本浏览器独立偏好，与简历数据分开 |
| 顶栏「浅色 / 深色」 | 工作台、面板、表单和弹窗 | 与界面语言独立；简历白纸、模板缩略图及导出配色保持原值 |
| 简历工具栏「简历语言」 | 当前简历预览、导出及相应既有双语字段投影 | 沿用每份ResumeView.locale，不受顶栏切换影响 |
| 编辑器「编辑字段」 | 仅显示中文、英文或双语输入字段 | 仅为编辑筛选，不翻译内容、不切换输出语言 |

初次默认中文浅色。偏好存于betterme.ui.preferences.v1，启动React前应用；切换不写Fact、简历版本或草稿。跨窗口storage事件读取最新偏好，仅更新显示而不回写，避免旧事件相互覆盖。存储不可用时当次切换仍工作，并说明无法记住偏好。

使用显式中英文静态文案。用户简历/JD、版本名称、差异值、OCR原文、AI报告和外部异常不会被通用字符串翻译。已产生并保存在状态中的通知可保持操作发生时的语言。简历切英文仍遵循既有字段回退规则，缺失英文不会自动调用AI补译，投递前需检查。
