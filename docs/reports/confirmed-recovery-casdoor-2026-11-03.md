## 统一鉴权边界

沿用本机账号服务及 stable owner；增加官方 `openid-client` 6.8.9 和自部署 Casdoor v4.25.0 的授权码 + PKCE。仅受信任服务端配置决定 issuer/client/callback；验证 RS256 签名、issuer、audience、nonce、state、有效期和单次流程，provider token 不落入浏览器或 Agent 记忆。

`issuer + sub` 是外部身份键，同名或同联系信息不自动合并。已有账号关联必须重新核对原本机密码、捕获原 owner 与活跃会话；完成回调前再次校验。新登录、退出、账号切换或新一轮授权会撤销旧流程，迟到回调不能给新账号设置旧会话。普通私有路由仍需 Bearer、HttpOnly 会话和 expected-owner；仅精确 GET OIDC callback 在网关允许跨站重定向，由 state/浏览器绑定与 JWT 校验接管，未放开其他接口。

本机原生 Casdoor 仅监听 `127.0.0.1:18000`，随机管理员/客户端秘密与独立证书，权限 0700/0600，`initDataNewOnly=true`。实测首次并发登录暴露 SQLite 写锁，修复为 WAL + busy timeout 后真实并发重测通过。上游默认 RADIUS 会监听非 loopback，已禁用并核对该进程没有 UDP 监听。

仅配置用户名密码注册/登录；QQ/微信的官方应用、邮件/短信发送 provider 尚未提供，不能宣称这些渠道已接通。当前本机账号没有自动与 Casdoor 绑定，需本人从「工作台设置 → 关联 Casdoor 统一登录」核对本机密码并完成 Casdoor 登录；未关联身份直接登录将进入独立新空间。[部署、绑定和渠道说明](../casdoor.md)。

| 边界 | 证据 |
| --- | --- |
| 归档只归目标账号 | A 读回，B 不可见；重复安装幂等，变更计划拒绝；并发 CAS 8 次仅 1 次成功，原归档未变 |
| 恢复工作副本 | 同档案 8 个并发 IDB 打开只 seed 一次；已有编辑不替换；A→B 后迟到 fetch 不创建数据库；默认空间键不变 |
| 身份切换与迟到流 | 已有 owner 代次、锁定页面、旧 body/克隆/SSE/401 不能进入或失效 B；本轮补 OIDC 迟到兑换、退出后回调与关联竞争 |
| OIDC 负例 | 错 state/浏览器、重放、issuer、audience、nonce、签名拒绝；绑定冲突、旧 cookie 与取消守卫拒绝；8 个并发同主体保持一个 owner |
| 真实 Casdoor | 两个随机合成账号真实注册/授权码/PKCE/签名 JWT；并发登录 owner 不同、重复登录 owner 不变；同 key 对话互不可见 |
| 并发任务与迟到结果 | 真实 Casdoor 身份 + 隔离临时 Host：A/B 同项目/幂等 key 分别启动；B 先完成，A 退出后才完成；B 记录未变、不能读 A；A 重新登录回原 owner 并取回自己的结果 |
| 真实 UI | 恢复简历、7 个版本链接、两份 23/10 消息历史、统一 Agent 23 条消息与原目标账号已核对；原默认资料未替换 |

真实协议验收使用临时 Host、内存 checkpoint 与确定性注入推理器；不读取真实简历或调用真实/付费模型。合成 Casdoor 账号和私有临时测试目录保留，没有为了清理而删除账号。普通单元/HTTP 测试的虚构 IdP 成功不代替真实协议验收。

最终全量：3638 项，3628 通过、0 失败、10 项既有跳过；类型检查 13/13、构建 8/8、零警告 lint、memory 与 diff-check 通过，额外严格类型检查覆盖新增 Host OIDC/恢复测试、真实验收脚本和 Web IDB 测试。构建仍有既有的大 chunk / Node 浏览器 externalization 提示，不隐藏或降低门槛。

## 运行与范围

正常 Web/岗位服务保持原开发入口，Host 仅在核对进程归属后重启加载本轮配置；Casdoor 原生进程单独保持运行。不启 Docker、不操作已有容器；没有暂存、提交、推送或发布。既有岗位/采集/主题/引导改动保留。

开始时 99 个既有脏文件：83 个无关文件指纹不变，16 个明确重叠的本轮源码、说明及交接文件有更新，未丢文件；仍为原 agent-os / HEAD，暂存为空。新增源文件和新增依赖只服务于本轮恢复/OIDC边界，不将历史工作归为本轮完成。

仍非本轮结果：公网 SaaS、岗位数据多租户、多实例并发写、OS/凭据隔离的原生 CLI、跨浏览器默认简历同步、本机密码重置、第三方渠道实测以及历史 checkpoint 逐 thread 确权。Casdoor 登录成功不等于这些边界已完成。
