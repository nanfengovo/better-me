## 三个工程模块与使用路径

- **Runtime**。自研任务执行与共享预算、工具授权、明确人工确认、进程强制终止后的恢复及幂等回执有专项测试。新增输出截断恢复、引用范围核验和调用结果归档。代码回归包括真实 Host 进程重启和迟到输出拒绝采用。[进程重启验收](../../apps/agent-host/tests/agent-runtime-restart.test.ts) · [截断及迟到响应](../../apps/agent-host/tests/resume-text-recovery.test.ts)
- **Knowledge & Memory**。本机 BM25 和字符 TF-IDF 向量余弦检索、授权项目材料、来源替换关系及只读取证共用持久执行状态。相同项目标签与文件名按独立项目标识和授权隔离。已确认项目理解可重读，失效引用暂停，并要求新一轮核对。事实、推断、未知分别呈现。[项目 Host 验收](../../apps/agent-host/tests/project-understanding-task.test.ts)
- **Evaluation**。使用固定数据集、实际模型返回、提示版本、可切换检索版本、执行回执及可重放报告。此前仓储同题两种独立模型 × 两种提示 × 两种检索方案的八格矩阵保留 2/8 全对，证明旧自由生成方案的局限。新版实际任务路径改为短编号选择和 Host 证据校验，在新的三组案例上按逐项标准验证。实付费用没有账单证据时保留未知；已有可选费率估算入口。[前次版本矩阵](./agent-runtime-knowledge-evaluation-2026-11-20.md) · [评测运行命令](../../evals/resume-quality/README.md)
