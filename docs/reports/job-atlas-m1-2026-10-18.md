## 实际交付

`packages/source-adapters` 提供明确安装的适配器注册表和五种适配器：Greenhouse、Lever、Ashby、通用字段映射 JSON、GitHub JSON 线索。每个适配器声明版本、返回实体和真实远程筛选能力。同协议公司的 board / 端点 / 字段映射由配置控制，不把用户给出的几个仓库或公司写进前端。支持不了的关注筛选明确返回 ignored，由应用层做本地筛选。

来源发现通过 GitHub repository search 或种子链接产生候选；可检查最多三个 JSON / CSV / Markdown 样本的结构和字段覆盖，并提出禁用、待审的配置。CSV / Markdown 可检查结构，尚无对应生产岗位解析器；提案不会自动安装外部代码、启用来源或把招聘活动变成单岗。四份公开示例默认全部禁用。

`apps/job-service` 是独立于 Vite 的 TS 服务，使用 Node 内置 SQLite。公开岗位、公司、来源、地点、薪资、Listing、不可变观察和 JD 分表存储并做完整引用验证；发现线索另表存储。HTTP 路由和未来 Agent 入口调用同一注册表。实际 `jobs.search` 查询持久库，与 HTTP 返回相同查询快照、列表、全量计数和地图桶。

按关注岗位 / 地区 / 公司手动刷新支持分页、处理预算、真实上游接收计数、本地匹配计数、部分完成、429 和 Retry-After、取消、同源 generation 与迟到结果阻断。完整 board 的协议可能一次返回全部 JSON，`maxRecords` 限制处理量，不能承诺上游只发送相同数量；实际网络字节另受预算限制。来源失败或列表缺席不把旧岗位改成关闭。

重复刷新保留稳定身份，未变化 JD 不重复复制正文；同一 run 的分页重叠去重，不同 JD 追加新快照和观察。来源缺值保留旧已知内容，明确改为远程时不继续保留本来源旧办公室为当前工作地点；远程资格范围参与关注区域筛选，但不冒充办公室坐标。稳定 Listing 的实际雇主发生变化时停止并要求核查，不静默套用旧公司。公司控股方不从品牌或 ATS 域名推测。

配置更新使用显式 `sources.register` 和 revision，不让来源观察覆盖端点 / 启用 / 归属策略；修改配置使旧 run 失效。SQLite 事务保存幂等回执和任务状态，刷新请求的完整规范输入指纹与有效处理预算分开。备份 / 恢复是严格 JSON envelope，保留公开库与任务事实，不执行上传 SQL，不包括浏览器简历、私人材料或服务 token。

## 运行和网络

CLI 要求明确的绝对私有数据目录和精确 UI Origin；默认 `127.0.0.1:5178`，也支持 `::1`。token 首次随机生成并复用，日志仅显示文件路径。Host、loopback 对端、Bearer、Origin、JSON 类型、请求大小和写入幂等键独立检查；不开放任意 URL 代理。

独占目录锁防止两个进程共同拥有数据库。只有取得归属后才回收中断任务；关闭时先停止 HTTP / 取消运行，等待操作结束后再关库释放锁。死亡所有者的锁经复核后改名隔离，`.job-service-stale-*` 保留证据；不确定、外机或损坏锁不自动删除。Windows 账户目录 ACL 未由代码验证；POSIX 已有目录要求私有权限，新建目录 / token 分别为 700 / 600。

受控 HTTPS 逐跳检查已配置 host / 路径 / 重定向和全部 DNS 地址，固定已核公网 IP，保留 TLS 原主机名；禁止私网、环回、metadata 和 Fake-IP，计实际请求 / 字节、每源每 host RPM、超时和取消。默认使用系统 DNS。本机代理实际返回 Fake-IP，默认请求因此被拒；显式 `--dns google-doh` 采用固定可信 HTTPS provider，DNS 请求也计预算，不修改系统设置。实机证据见 [有限来源探测](job-atlas-m1-source-probes-2026-10-18.md)。

启动和完整 API 示例见 [服务 README](../../apps/job-service/README.md)，协议与扩展方式见 [适配器 README](../../packages/source-adapters/README.md)。

## 仍未完成

FTS5、CJK token 与 RTree 已建，但 `candidateIds` 返回完整安全候选集及命中诊断，实际业务查询仍扫描并验证完整快照；写入会重建关系 / 索引。本阶段不承诺大库吞吐或索引加速，后续须做容量测量与不丢模糊候选的优化。

新服务尚未接入网页和旧 Windows 浏览器 companion / 腾讯读取器；现有四平台单岗能力保留，不能把本次 ATS 列举外推为 51job / BOSS / 猎聘 / LinkedIn 全站搜索。跨源同岗的候选 / 确认 / 拆分、地理编码、企业修订 UI、家庭设置、正式三维视觉与性能、私人收藏 / JD 匹配 / 材料联动仍需继续实现。没有迁移真实用户数据，也没有重验旧 119 模板 / 主题的全部视觉组合。

Pages 与现有 Docker 仍是静态工作台；完整本机 UI 接线、服务容器化和服务器认证另做。JSON 中的“公开字段”表示与私人材料分离，不能据导出按钮推断来源内容已经获准公开再分发。未来 LangChain / LangGraph 包装同一工具，不在本轮提前安装 SDK 或复制主库。
