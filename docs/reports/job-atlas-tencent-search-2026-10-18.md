## 实现与边界

新增 `tencent` / `1` 适配器，复用既有 `SourceRegistry`、版本化来源配置、受控 HTTPS 传输、来源预览与手动刷新工具。配置示例在 [examples.json](../../config/sources/examples.json)，默认禁用、待审核；不会启动即采集。代码与 Schema 见 [tencent.ts](../../packages/source-adapters/src/adapters/tencent.ts)、[tencent-contracts.ts](../../packages/source-adapters/src/tencent-contracts.ts)。

请求主机固定为 `careers.tencent.com`，路径固定为 `/tencentcareer/api/post/Query`；关键词通过 `URLSearchParams` 编码。来源 JSON 无法指定任意请求 URL。每次列表调用只读取一页，页游标绑定来源、配置与关键词；多个关键词各自分页、按 OR 处理，不把可能重叠的 Count 相加。地区和公司关注条件由应用层本地检查，并在覆盖信息中保留上游未执行的事实。

岗位采用 `PostId` 作为源身份；官网链接必须与此 ID 一致，也允许腾讯官方 Workday 的固定 HTTPS 详情路径。搜索列表只提供职责摘录；下述初始三页探测没有读取详情。后续集成中已增加显式开关与上限的详情补全，见文末。原始国家、地点和更新时间保留；只有 `CountryName` 明确为“中国”才写 `CN`，不会凭中文城市名猜国家、坐标、薪资或企业控股方。

`LastUpdateTime` 不是发布时间。`DateCreated` 语义尚未核实，只保留来源证据，不写入 publication；`IsValid` 也不视为独立在招核验。availability 保持 `unknown`。
