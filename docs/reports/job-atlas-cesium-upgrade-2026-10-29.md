# Atlas 三维地图升级：实现、验收与未完成项

日期：2026-10-29。交付位置：独立功能分支 `feature/atlas-3d-modular-20261029`。本报告是源码与合成验收记录，不是 Google 实景覆盖证明，也不是生产上线声明。

## 结论

已实现 CesiumJS 1.146.0 的实际渲染链路、三种地图模式、显式 Google/授权 3D Tiles 配置、差量点位更新、相机/详情联动、静态资源与故障回退。保留默认 MapLibre 工作地图；没有将装饰性 Three.js 模型当作真实建筑。

**尚未完成真实 Google/上海验收，浏览器增量期间仍有长任务和查询呈现延迟，不能宣布“三维升级及性能全面完成”。** 本次推送用于保存与审阅当前阶段，不直接合并 main。

## 实现边界

- `AtlasMapViewport` 负责模式、权限确认、画质和内存态配置；React 状态不向 localStorage/IndexedDB 写 Google Key。
- `map3d/config.ts` 校验数据源、画质预算和脱敏错误；没有 Key 不调用 Google factory，也不触发 ion 的隐式替代。
- `scene-model.ts` 是独立纯业务投影：真实坐标分组、ID 去重、精度过滤与差量更新。不依赖 React、SQLite、查询索引或动画。
- `cesium-runtime.ts` 封装 Viewer、相机、billboards、边界与 tileset 生命周期；后台数据更新不创建新 Viewer，不自动拉走用户相机。
- `CesiumAtlas.tsx` 只负责适配业务选择/聚焦与 React 生命周期；地址选择器有查询和有界 DOM，重合点可选择多个实际岗位。
- `server/cesium-assets.ts` 按白名单提供 Workers/Assets/ThirdParty/Widgets、WASM MIME 和第三方许可；路径跟随 Vite base。

本地地球使用 SDK 随附 Natural Earth II 概览纹理及本地概略边界；不调用 ion、不加载 Google，且不称卫星实景。行政高亮保留来源环与岛屿，不拿城市中心当办公室。

## 渲染与资源控制

启用 requestRenderMode，时间变化不持续强制渲染；业务点位批量使用 BillboardCollection。相同输入不重新上传，单点变化只更新受影响点。缩放、朝北、选址与 JD 聚焦使用真实 Cesium 相机；各引擎保留各自原生相机，避免把 MapLibre zoom 生硬套成米高度。

质量档分别限制 DPR、屏幕空间误差、tiles cache/overflow（64/32、128/64、256/128 MiB）。这些不是浏览器/GPU 总内存硬上限。默认无自动旋转；用户开启时仍遵循减少动态效果、可见性与操作暂停。

迟到的异步 tileset 在卸载后销毁；source generation 防止旧响应覆盖新来源。factory、tileFailed、renderError 和 context loss 分别处理。渲染已失败时，后到的 source-ready 不能把错误遮掉。

400/401/403 提示核对凭据/API/账单/限制，403 保留地区条款等不确定性；429 不密集自动重建 root；网络超时不冒充地区无覆盖。异常不输出可能带凭据的上游 URL。SDK 和动态数据署名保留。

## 浏览器发现并修复的问题

1. 本地世界多边形默认 RHUMB 细分可触发极区巨大三角剖分，出现 RangeError 并停止渲染。改为 GEODESIC，并将全球概略展示改为线轮廓 + 本地纹理，避免对整个世界做填充三角化。
2. 贴地多边形轮廓存在 SDK 不支持路径，改为显式来源环 polyline；原始经纬度不做随机偏移。
3. 短地图容器中的地址选择器曾被顶部/底部间距挤成零高度，调整锚定与底栏后，真实浏览器可以滚动并选址打开 JD。
4. React StrictMode 弃置挂载不再重复创建渲染器；resetRevision、后台进度和画质更新不重建 Viewer，错误重试才显式重建。
