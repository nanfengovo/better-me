## 真实验收与部署边界

- 本机真实 LinkedIn 详情的一次请求收到上游 HTTP 429，猎聘/51JOB/BOSS Node 直连失败。因此四平台的真实成功采集尚未验收；代码提供公开提取、明确失败与文字/截图回退，不绕过登录、验证码或反爬。
- 真实云模型 OCR、私人扫描件 OCR、头像识别保真、六模板多页打印 PDF 与实际 ATS 解析尚待样本验收；浏览器/单元测试不能替代这些流程。
- JD 提取服务来自 Vite dev/preview；纯静态发布 `dist` 不自带该服务。生产静态托管需另部署兼容接口，或者使用文字/截图。
- 草稿/文档/JD 配置按浏览器来源保存在 localStorage，历史在 IndexedDB。存储被拒绝或清理仍会影响恢复；错误提示与备份入口可见。
- 版本总量为 50，命名检查点也计入上限；这不是永久留存或跨设备同步。完整文档 JSON 不含版本历史、AI 配置/Key、JD 草稿或截图；未完成草稿 JSON 需修正，不等于有效备份。
- DOCX 导出、AI 建议逐项应用、多简历管理、完整历史链导出/导入仍待实现。模板为自研，未移植商业站资产。

本轮使用说明更新于根 README，产品/存储/JD 取舍追加于 `.agent-memory/decisionLog.md`，后续优先使用真实样本验收，再按反馈决定上述补齐项。

## 追加反馈：拖动分栏与预览跟随

用户要求左右两栏可自由拖拽调整占比，预览实时跟随左侧编辑与移动。新增独立分隔组件，默认编辑区 38%，拖动时显示即时占比；根据可用宽度保留编辑约 300px、预览约 340px，避免任一栏不可用。比例独立保存在浏览器偏好中，双击或 Enter 重置；方向键、Shift、Home/End 可操作。≤940px 使用上下布局，打印隐藏分隔条。

六套模板使用稳定的个人字段、经历与要点 ID 锚点。左侧点击、聚焦、输入与实际滚动发送当前语义目标；右侧只滚动纸张容器，已可见的短字段保持位置，长段落按内部进度定位。隐藏项仅按明确父级回退；拖动分栏维持最近语义目标并按新宽度定位。预览默认使用 ResizeObserver 适应真实画布宽度，手动缩放范围为 20–130%。「跟随编辑」可关闭并记忆偏好；手动浏览右侧暂停，新的左侧交互恢复，高亮不进入打印。

## 追加反馈：自动保存开关与触发条件

用户认为正式保存过于频繁，要求开关及自定义条件。本次替代最初固定 650ms 正式保存：顶部开关可关闭自动保存，设置面板提供「按下回车」（默认）、「停止输入后」、「离开编辑项」三种条件。停顿自定义 1–300 秒，默认 5 秒；自动历史合并默认改为 60 秒，可调 15–600 秒。偏好按浏览器来源独立保存，不进入文档、备份或历史。

每次修改仍尝试写入独立草稿，不生成历史。满足条件并通过完整校验才更新正式文档；关闭后可用立即保存/Ctrl/Cmd+S。刷新/隐藏页面不会绕过回车、失焦或关闭条件，恢复有效但未提交草稿也继续等待条件。初始化草稿写失败会明确报错。条件/开关变化取消定时和未开始的自动写入，已开始写入与手动恢复/检查点允许完成。跨窗口冲突继续暂停，需手动保存才采用当前内容。

Enter 在 keyup 后下一帧提交，覆盖本次换行的 React 更新；排除输入法候选确认、Shift+Enter 与其他组合键，只响应简历编辑字段/名称，不响应 JD、AI 或保存设置输入。自动历史沿固定时间窗口合并，无变化不建版本；命名检查点、导入与恢复独立保留。

独立演示来源浏览器验收：

1. 编辑名称后显示「草稿已保护」，按回车才变「已保存」；Shift+Enter 保持等待。
2. 关闭开关后编辑并按回车，保持草稿；刷新保留关闭偏好与原输入，仍未自动提交。立即保存成功，提示为手动保存。
3. 选「离开编辑项」时输入未立即保存，点击设置离开字段后成功保存。
4. 自定义停顿 2 秒与合并 120 秒后，等待完成自动保存，重新打开设置值保留；验收后名称与推荐设置恢复。
5. 390×844 面板完整落在视口内，无整页横向溢出；临时视口已恢复。关闭设置不丢尚待 blur 提交的有效秒数。

最终 **123 / 123 测试通过**，新增 11 项覆盖策略边界、错误偏好、首次配额失败、关闭/改条件取消旧计时与排队自动保存、刷新草稿、手动保存、冲突与合并窗口。全量 lint、typecheck、build、memory:check、git diff --check 通过；构建保留原有主包体积提示。代码与记录均在本地工作区，无新增提交或 push。
