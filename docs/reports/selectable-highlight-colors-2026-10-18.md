# 可视高亮色板与自定义颜色 · 2026-10-18

用户先要求高亮颜色可选，随后指出文字菜单缺少视觉预览。本轮将最初的六色色名 select 升级为可视色板，并支持任意安全六位 Hex 自定义色；下述为最终行为，取代首次文字菜单的交互说明。

## 使用与预览

- 选中文字后，点击高亮旁带底色的 A / 下拉箭头展开色板。高亮图标仍单独开关；没有选区时禁用。
- 黄、绿、蓝、粉、紫、橙显示真实底色，当前预设色显示勾选，混色提示可统一。窄面板自动换行，色块最小宽44px。
- 悬停或键盘聚焦只在白纸预览中显示所选文字效果；点击色块才应用，色板保持打开，可以连续改色。
- 自定义支持原生拾色及 `#RRGGBB` 输入。编辑先预览，点击“应用颜色”或有效Hex输入中按Enter才提交；非法值提示并禁用应用。
- 已有高亮可以直接换色，保留粗体等其他样式、相邻范围及原文。正式简历预览在提交时同步更新。
- Escape/关闭按钮返回正文原选区且阻止事件关闭外层；外部点击关闭不抢目标焦点。重开丢弃未提交草稿。
- 打开时捕获正文与选区。正文变化永久作废，撤销回旧文本也不复活；textarea键盘改选区关闭旧面板，重开使用新范围。Hex输入自身的选择不影响正文范围。
- 中英文界面及深色适配；局部预览保持白底深字。面板在字段普通文档流中，短屏可随编辑区滚动。

## 保存与兼容

颜色是ResumeView格式元数据，不修改Fact。`TextStyleRange.highlightColor?: "#RRGGBB"` 与 `highlight` 开关共存；无色旧数据用 `#fae6a1`。Schema及运行时helper严格校验，损坏草稿回退黄，不接收任意CSS。

范围拆分、编辑重映射、双语字段投影、JSON/备份、快照、差异摘要与逐项恢复保留颜色。关闭高亮清除颜色并保留其他样式。HTML/Markdown仅使用安全Hex；DOCX自选色写精确OOXML run shading，旧无色仍Word黄色。RenderCV YAML沿用不映射局部样式的边界。

PDF打印沿用 `print-color-adjust: exact`，本轮未逐页打印PDF；打印端背景设置仍会影响结果。
