## 诊断与修复

前一轮在正常应用的既有示例草稿中，以 1512×827 CSS 视口复现：右栏约707px，伴写卡片堆叠后预览正文仅210px，外层只有约2px滚动余量。实际纸张内部可滚动，故不将问题误判为全局滚轮失效。

按高度预算、Agent 堆叠占用、嵌套滚动三个假设检查后，本轮先添加可失败的收起回归：缺少独立收起按钮时失败，再实施修复。

| Before | After | Why |
| --- | --- | --- |
| 工作区最低540px，顶部内容与长对话共同挤压纸张 | 桌面最低800px；窄屏预览最低900px，空间不足由页面纵向滚动承接 | 给编辑器与纸张保留实际阅读高度 |
| 卡片、项目理解和授权状态分散占用外部网格行 | 合并到有界 Agent 滚动区，普通宽度上下排列；右栏至少1000px才使用320px侧栏 | 长历史和授权控件不继续压缩正文 |
| 关闭项目理解会卸载组件；原收起按钮只折叠部分内容 | 增加完整对话收起/展开，隐藏而不卸载；保留原输入、选择、历史、请求和滚动状态 | 收起是空间操作，不表示停止、删除或重新发送 |

补充行为：

- 运行中收起仍显示真实的“伴写分析中/项目理解中”；任务终态不会自动展开面板。
- 项目理解标题在 Agent 内部滚动时保留；取消吸顶外部工具栏方案，避免页面滚动后遮住对话头部。工具栏可随外层页面完整滚动到可见范围。
- 收起后焦点回到展开按钮；支持键盘操作和 `aria-expanded` / `aria-controls`，隐藏区不参与键盘导航。未新增展开/收起动画。
- Agent 滚动边界不穿透页面；预览跟随关闭时分别核对编辑器和纸张滚动，避免把既有跟随功能当成串滚动。
- 引文连线依实际卡片是否位于纸张右侧判断，不再沿用旧780px阈值向上下堆叠卡片画跨正文连线。
- 既有共识确认、事实核对、CAS采用和撤销门禁保持不变。
