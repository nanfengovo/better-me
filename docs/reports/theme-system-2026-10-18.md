# 独立简历与工作台主题系统 · 2026-10-18

本轮按用户要求实现简历和整个网页的主题系统，与并行进行的开源模板接入分开负责。保留已有未提交改动，没有重置、暂存、提交或推送；没有给另一个聊天发送消息，也没有修改原 localhost:5173 的用户存储。主题验收使用独立 5318 origin、独立 Headless Edge context 和合成内容。

## 功能与使用

设计面板在模板库之后新增「简历主题」，提供 10 套原创主题：商务藏蓝、暖调编辑部、纯粹黑白、科技深青、沉稳墨绿、酒红典雅、石墨灰、北欧浅灰、岩青蓝、暖砂岩。主题卡片具有配色与字体样片、双语名称和说明、可访问选择状态。选择主题不会修改事实、内容顺序、显示开关、模板、字号或间距。

「沿用模板风格」保留旧版视觉；「推荐」只选择主题，不强行清除用户覆盖；「采用主题原始配色与字形」显式清除颜色及字体覆盖，保留字号、页边距、装饰覆盖和其他内容。旧简历如已保存完整默认 layout，也视为明确覆盖，不猜测原意；因此选择主题后可能继续显示旧颜色，面板会解释并提供恢复主题默认的操作。

顶栏新增工作台配色：森林工作室、藏蓝书房、梅紫画室、石墨工坊。每套分别支持浅色、深色，共 8 种外观。工作台配色与明暗使用浏览器偏好存储，支持首帧初始化、刷新、跨窗口同步和存储失败提示；独立于简历输出语言、简历主题及文档备份。工作台深色不会反转纸面。

## 数据与样式契约

- `packages/core/src/schema/resume-theme.ts`：版本 1 严格 Zod Schema，固定六种颜色、三种字体角色、标题/关键词/分隔线枚举，拒绝任意 CSS、外链字体和未知字段。
- `packages/core/src/themes/`：10 个独立 JSON 和 catalog，解析顺序、默认 ID 与注册一致性验证；共用主题深冻结。增加主题无需复制模板组件。
- `ResumeView.themeId` 与 `themeOverrides` 均为可选。未知但格式有效的 ID 原样保留，显示时确定性回退墨绿；无 ID 不进行静默视觉迁移。
- 优先级：主题默认 → 当前简历的视觉令牌覆盖 → 显式 `layout.accentColor/fontFamily`。字号、行高、分节间距和页边距仍只属于 layout。
- 新建 view 保存稀疏 layout；设计面板只写实际更改的字段。有主题的投影保留原始覆盖，避免展开默认值掩盖主题；旧视图投影仍采用旧默认行为。
- `resolveResumeTheme()` 统一供设计控件、纸面和 DOCX 使用；`getResumeThemeCssVariables()` 只输出纸面变量。工作台使用单独 `--workspace-*`、`--ui-*`，屏幕样式与打印隔离。

共享文件仅做必要接线：`ResumeDesignPanel` 加独立面板并保留稀疏 layout；`ResumeTemplate` 加主题变量与能力属性；`ResumePreview` 加打印纸色和 RenderCV 边界提示；`main.tsx` 最后导入两个新样式。不改并行需求的模板清单、来源授权和各来源 CSS，也没有复制整批模板文件。

## 模板与输出范围

当前注册的 119 套版式都能应用主题纸色、正文/辅助/强调色及正文/标题/姓名字体。6 套自研版式完整支持统一标题、标签与分隔线装饰；113 套来源适配保留自己的结构和特殊装饰，面板明确提示这一能力差异。主题适配层统一语义区域颜色和背景，并保留模板几何，不宣称所有特殊来源装饰都已转为公共装饰枚举。

预览与浏览器 PDF 使用同一 CSS；打印 helper 将主题纸色同时应用到页面画布，避免短简历下方变回白色。浏览器打印仍需开启背景图形。DOCX 映射固定 Word 字体族、六种颜色、纸色及可映射的标题/标签/分隔线，继续为可编辑单栏，Word 是否打印纸张背景由其设置决定；不承诺与 PDF 同版。Markdown 保留内容与强调，不复现配色。JSON 保留主题 ID 与覆盖。RenderCV YAML 使用其上游设计体系，并在主题文档导出时显示不复现网页主题的提示。

历史记录能列出主题选择与单个视觉令牌差异，并按 typed target 恢复。单项恢复保留其他主题令牌、最新模板、排版及事实；陈旧目标与非法值拒绝恢复。显式默认颜色/字体和「沿用主题」的历史语义可区分，英文 UI 有对应元数据说明。
