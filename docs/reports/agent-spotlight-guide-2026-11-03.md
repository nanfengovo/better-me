# Agent 协作场景统一为沉浸聚光引导 · 2026-11-03

## 结果

用户反馈侧栏教程不如原「初次见面」引导。现将八个协作场景接入同一套 `SpotlightGuide`：展示实际工作界面与当前控件，浮层逐步讲解，支持前后切换、跳过、续接、退出和实操交接。侧栏不再承载八宫格目录与长篇教程。

| Before | After | Why |
| --- | --- | --- |
| 窄侧栏同时显示目录、三步说明与练习 | 真实界面聚光 + 当前场景卡片 | 先看到当前要操作的位置 |
| 所有教学内容默认展开 | 操作说明、边界、示例合为一个可选展开区 | 阅读不是完成任务的前置门槛 |
| 总览和侧栏各自处理运动、焦点 | 两处共用原生模态、聚光测量和动效组件 | 复用用户认可的已有表现与行为 |
| 固定宽/高卡片可能盖住手机或横屏控件 | 窄屏利用上下空间，短横屏缩窄到控件旁 | 保留可见的实际入口与翻页操作 |

## 实现边界

- `apps/web/src/components/SpotlightGuide.tsx`：提取原引导的原生 dialog、SVG 挖空、标题焦点、键盘约束、减少动态效果与 250ms 可中断入场。Portal 放在 body，避免嵌入侧栏后被宽度、overflow 或 inert 限制。
- `FirstRunGuide.tsx`：保留首次弹出/输入保护、重播、独立偏好和欢迎/结束场景，只复用共享外壳。
- `AgentWorkflowGuide.tsx`：一次一个场景，默认收起示例；保留原章节 ID、阅读/练习分离和白名单进度，不迁移或重写旧记录。
- `AgentSidebar.tsx`：翻页只准备对应视图，真实工作区不再因教程而隐藏。固定 portal 插槽、任务寿命和输入节点保持不变；退出可回到非模态实操定位并返回本节。
- 聚光优先指向具体来源按钮、输入框、选择框或卡片标题；按视口及滚动容器裁剪，跳过隐藏控件，观察布局、滚动与展开变化。没有对应内容时如实显示前置步骤，不自动生成材料或请求。
- 模态中背景不能直接交互；「找到入口」先关闭引导，再显示现有实操定位教练。定位只滚动/聚焦，不点击、展开授权、发送、确认共识、采用候选或切换模型。
- 键盘操作取消运动，示例文本框的方向键仍编辑文字；系统减少动态效果优先。教程输入不持久化，不改自动保存、账号隔离、模型和授权策略。

另外实际验证：

- 项目理解资料范围真实 summary 获得聚光；「找到入口 → 重新定位」只聚焦，details 仍关闭，未授权。
- 实操定位 → 返回本节 → Esc，退出模态且焦点回到教程入口。
- 展开对话示例并输入纠正，左右键不换章节，输入不出现在教程持久化记录中。
- 确定性合成任务在引导打开、切到记忆视图期间完成；回到自由对话可见合成回复，原 composer DOM 未重建。
- 独立未发送草稿遍历八章后仍完整保留，还是同一个 composer DOM。
- 减少动态效果为浏览器仿真，不更改用户系统偏好；正常动效另行检查并在截屏前等待可中断入场结束。

上述结果证明 UI、焦点、草稿与任务交接，不证明真实模型质量、真实授权或 SaaS 安全等级。
