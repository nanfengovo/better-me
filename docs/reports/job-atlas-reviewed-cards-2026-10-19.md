# 四平台卡片审核入统一索引

日期：2026-10-19。回应用户“搜索仍只有腾讯这一条，来源太少”的反馈。前一批已增加来源目录并把本机有限索引扩展为 49 岗 / revision 22、C# 13 个文本命中 / 8 家企业；本批补齐原站搜索卡片经本人核对后进入同一索引的通路，以及原站首屏加载等待。

## 结果与适用范围

正式主 UI 的猎聘 `C# / 上海` 首次读取返回 22 张当前页卡片，无需再次读取。选取一张原文核对并明确确认后，本机统一索引 **49 → 50 岗、revision 22 → 23**；清除上海原文条件后，C# 为 **14 个文本命中 / 9 家企业**。这是一张新增卡片摘要及当前已收录文本的结果，不是个人资格匹配、全市场数量或四平台全量覆盖。

卡片读取仍由本机 Vite 的专用浏览器宿主完成；审核入库由独立本机岗位服务执行。静态 GitHub Pages 和 nginx Docker 不包含浏览器宿主或 SQLite 服务。已有 9 个可抓取来源保留，新增人工核对来源无同步能力，不计为新接通的原站采集接口。

## 共同工具与 HTTP

新增严格共享契约位于 `packages/source-adapters/src/reviewed-cards.ts`，工具实现在 `apps/job-service/src/reviewed-cards.ts`，经 application 注册后由 Web 与 HTTP 复用：

| 工具 | HTTP | 行为 |
| --- | --- | --- |
| `jobs.preview-reviewed-cards` | `POST /api/v1/jobs/reviewed-cards/preview` | 输入 `{ provider, pageUrl, capturedAt, cards, expectedRevision }`，核对平台、链接、可见原文和当前版本，返回预览指纹与稳定岗位身份；不联网、不写索引 |
| `jobs.import-reviewed-cards` | `POST /api/v1/jobs/reviewed-cards/import` | 重交完整预览输入，并提供 `previewFingerprint`、`reviewed: true` 和 `Idempotency-Key`，原子写入后返回耐久回执 |

每次 1–50 张卡片，支持 `51job | boss | liepin | linkedin`。雇主必填；可选的地点、薪资、发布时间若提交，必须逐字段提供相同值的证据，非链接值也必须出现在卡片原文中。只允许该平台的官方 HTTPS 搜索页和稳定单岗链接；跟踪 URL、LinkedIn 标题 slug 不改变岗位身份。任意数据集、坐标、控股方、核实状态和来源端点策略不属于输入字段。

工具接受**用户提供并明确核对的证据**，不认证它一定来自受管浏览器，也不独立核实岗位仍在招。记录保留原平台、搜索页、单岗链接、逐字段证据及卡片摘录。每个平台采用 `reviewed-platform-<provider>` 的保留元数据来源；配置禁用、无同步能力和网络权限，若同 ID 已有来源定义不同则拒绝写入。

预览绑定索引版本和完整输入指纹；版本变化时重新读取、预览和确认。导入将主机计算的完整命令指纹与回执一起写入 SQLite；丢失响应后，同一 body / revision / 幂等键可取回原回执，即使索引已前进或服务已重启；同键不同内容冲突。客户端取消等待不等于数据库回滚。

## 投影和事实边界

- 卡片以 `excerpt`、`availability: "unknown"` 保存，浏览器提取方法和 parser / unverified 标题独立记录。后续本人重新核对的新标题可更新 parser 标题，真正的人工标题覆盖继续受保护。
- 低完整度摘录追加证据和快照，不替换已有选中的完整 JD / 描述。快照身份包含内容、完整度和提取方法，兼容已有快照 ID。
- 捕获身份由版本、平台、搜索页和读取时间组成，不由本次选择的卡片子集或顺序组成。依次核对 A、A+B、B+A 不重复追加 A 的相同观察；改变 A 的原文仍保留新观察。
- 地点只保留原文，`kind: "unknown"`；不从平台、搜索地区或地名补国家、行政区、办公室或坐标。全球关键词 / 地点原文可检索，国内 / 国家 / 结构化省市区条件可能排除这类未知记录；缺坐标不画办公室点，不参与凭空计算的距离。
- 薪资保留原文，不猜币种、数值、周期、税制。发布时间仅对已经带时区的合法时间戳建立时间字段；相对日期和无时区原文保留，不把活跃、在线、刷新或读取时间当发布时间。

## UI 与等待行为

原“核对并收藏此岗位”继续预填私人机会草稿。有企业字段的卡片新增“核对并加入统一索引”：显示字段和可展开原文 → “预览入库变化” → 明确勾选待核实摘要确认 → “确认加入统一索引” → 重读真实快照。

回执未知时保留原请求，提供“重试本次写入 · 核对回执”；明确陈旧或无效时清除旧预览和勾选。已取得成功回执但刷新失败时显示已提交版本，仅重试读取索引。更换连接 / 令牌 / 卡片绑定后隔离迟到响应；关闭中止等待。客户端等待上限为 25 秒，系统减少动态效果设置下停用相关过渡。

原站加载显示等待动画。`unknown_layout` 在已有读取中获得固定 8 秒被动采样宽限，结构变化不能无限续期；可读 / 明确空结果仍要求稳定 800 毫秒。没有新增导航、自动点击、翻页、选择器放宽或验证绕过。取消后停止等待并保留原 owned page，供明确再次读取。
