# 统一 BetterMe Agent：共识、历史、任务与成长

日期：2026-11-01。现有 `agent-os` 工作区，基线 HEAD `7135a43e3aab1afe2f9337cca8042ef5cf4bb3fb`。本轮未暂存、提交、推送或操作 Docker；未操作真实简历、岗位、业务项目、既有浏览器或原服务。

## 已接入正式应用

`App.tsx` 在文档范围提供同一个 Agent 内核，简历伴写、浮动伴侣、职业成长与项目理解复用它；不是把测试页面作为产品功能。现有单字段写入 CAS、受控取证 Host 与成长计划仓库仍保留各自职责。

- 独立 IndexedDB `better-me:agent-continuity:v1` 保存文本历史、任务、已确认共识的版本指针与成长事件。不打开或迁移简历、岗位、凭据数据库。
- 项目共识默认不跨入口共享。项目级开启共享后，每次请求还需明确同意。发送前及采用返回值前，重新核对 Host 会话、工作区、原文、版本、摘要哈希和本地授权。只传术语、系统边界、未知项，不传取证代码全文，不把项目能力记成本人功劳。
- 统一面板提供任务、共识记忆、全部文本历史检索与逐页显示、成长目标与时间线、下载备份。模型只接收明确允许的必要窗口，不把全部历史无差别发送。
- 已撤销共识或关闭简历摘要共享所派生的伴侣消息仍可回看，但不会被自动重发。原文改变、隐藏、删除或授权版本变化会使旧共识失效。
- 三个入口共用显式的当前模型/ChatGPT 账号与模型选择；不会从账号通道切到付费 API。授权控件关闭不是撤销账号，不能因此误关其他入口的可用状态。

## 连续性与恢复

- 正常切换应用页面、成长子页、收起伴写/伴侣只隐藏视图，不卸载进行中的会话；任务与结果仍登记到统一历史。
- 更换简历作用域、模型或授权属于有意改变执行范围，仍取消相关请求，拒绝迟到输出。隐藏页面不会自行启动主动模型追问。
- 统一任务显示真实等待、模型目标、已知阶段和等待时长。长时间没有新进度会明确说明未知，不伪造百分比。
- 浏览器关闭/重载不等于本机请求能继续执行。重载后把遗留本机任务标成“待手动恢复”，保留历史，不自动重发或计费；已有 Host 项目任务由统一层继续核对状态。
- 内核对本机模型等待设置三分钟上限；调用方已有更短超时仍有效。超时、额度失败、停止保留输入与记录。保存冲突或磁盘失败会停止本轮并展示未可靠保存，不能显示成成功。

## 成长不是后台监视

跟踪默认关闭，开启后仅记录此后的本人确认操作：项目共识、采用表达、采纳学习方案、学习证据提交、本人任务状态。统一目标可以明确带入现有成长阶段，但不替换已有计划。规划仍由用户点击发起，携带本轮授权共识、统一目标和近期事件；不会自动轮询付费模型、读取其他应用、认证能力或修改简历。

当前支持的是同一浏览器、同一文档范围的持续记录与规划衔接，不宣称跨设备同步、关闭浏览器后自主运行、无限模型上下文或完整跨项目人格画像。原始学习证据继续留在成长仓库，统一时间线只记录必要元信息。

## 实际浏览器回归

独立 Playwright 会话 `betterme-unified`，独立源 `http://127.0.0.1:5201/tests/ui-lab/unified-agent.html`。夹具挂载正式生产组件与内核，使用虚构用户、虚构项目、独立浏览器存储和可控延迟/错误的模型适配器。Fetch 保护在网络发送前阻止真实 Host/模型请求；检查 `forbiddenRequests` 为空。没有访问正常 5173、5197/5207 授权环境、真实文件或数据库。

| 流程 | 浏览器观察/断言 |
| --- | --- |
| 项目理解 | 发起后切到成长页，统一任务仍可核对；模型完成后等待本人确认；确认后进入共识记忆，默认未共享 |
| 伴侣 | 显式项目授权和本轮授权后，实际请求含同一确认版本的术语边界/成长目标；收起伴侣并换页，请求继续完成 |
| 职业成长 | 使用统一目标与共识完成分析、候选方案；生成时离开页面仍完成；本人采纳、提交证据、改变任务状态进入成长时间线 |
| 简历伴写 | 补充虚构个人动作并确认后发起生成；立即换页，返回后候选保留；不写入真实简历 |
| 历史 | 统一面板能检索项目理解、伴侣、成长、伴写记录；刷新后伴侣历史仍在，未自动调用模型 |
| ChatGPT 路由 | 选择虚构账号与模型，伴侣和成长使用同一路由；关闭伴侣不会误关成长入口；额度失败仅产生一次账号调用、没有当前配置 API 回退、草稿保留 |
| 授权失效 | 源会话撤销材料授权后，下一次共享请求在模型调用前被拒绝；输入保留，模型调用计数不增加 |
| 重载恢复 | 请求已登记并到达隔离提供方时刷新，遗留本机任务标为“页面重载 · 待手动恢复”，本页模型调用数为零 |
| 布局 | 1200×818、390×844、1200×600；统一历史/任务独立滚动，模型设置不挤占聊天区；手机与短屏聊天区均保留至少120px读取高度 |

实际截图检查发现并修正了授权表单把伴侣聊天区挤扁的问题：模型/授权改为独立可收起设置层，不改变聊天区高度；短屏使用紧凑布局；统一面板的层级高于伴侣，避免从伴侣进入后被挡住。样式使用现有主题令牌，不添加装饰性进度或打字延迟。

最终1200×600短屏聊天读取高度实测124px；统一面板历史可独立滚到底部，Escape收起后焦点回到触发按钮。从伴侣打开统一面板时关闭按钮命中正确，没有被伴侣遮挡。通过正式主题设置切到深色，统一面板表面为 `rgb(35, 39, 37)`；减少动态效果下交互通过。最终重载文档控制台0错误/0警告，模型调用0、真实服务拦截记录为空。

- `unified-agent-growth.png`：确认事件、方案、提交与任务变化。
- `unified-agent-mobile.png`：手机伴侣聊天与错误恢复。

**这验证的是正式模块的交互、授权和路由逻辑，不是真实 ChatGPT 账号资格、额度或生成质量验收。** 本轮未再次发起本人登录，也未用真实套餐调用。
