# 国内投递准备与本人回执 · 2026-11-05

## 交付范围

复用正式「机会与投递」和机会库，不增加第二个聊天 Agent。BOSS、51job、猎聘的官方 HTTPS 岗位链接可创建发起沟通、共享简历、岗位申请三种独立行动卡；准备、逐卡核对、本人平台操作、实际结果分开。当前不控制手机、不采集平台、不自动发消息或投递；没有防封承诺。

核对绑定当次岗位正文、链接、账号标记、对象、文案、不可变材料快照及平台简历/附件分享范围。岗位或所选材料变化/删除使旧准备失效；已打开或结果不明的行动不能通过取消绕开核实。相同岗位/平台/账号标记/对象/动作的待办或已完成卡阻止重复准备；只有明确未发或未交接的取消才可重新准备。

本人回执保留结果、说明、实际发生/核实时间、记录时间和依据，不代表系统读取了平台。发招呼、共享简历不算岗位申请，回执不会自动改投递阶段或生成沟通日志。完整机会库派生站内待核实队列，不因当前筛选遗漏；没有系统通知、微信/SMS/Web Push 或后台调度。

## 数据与发布隔离

- 机会记录复用原保存、版本冲突与损坏保护；旧 v1 保持可读，首次使用行动卡升级 v2，旧客户端拒绝读写，避免静默裁掉新字段。完整 JSON 往返保留卡片与回执，删除全部岗位不降级。原 4 MB 备份边界不变，每岗 20 张卡是资源上限，不是平台允许发送配额。
- 原工作树存在账号隔离、能力工厂、写作和岗位采集等并发未发布改动。本批从已发布 HEAD 独立导出，仅纳入本功能及必要文档/Compose 小改动，不将它们混入发布；原 `private-storage` 引用及 README 账号说明保留在工作树，不纳入本次提交。
- 不触碰真实简历/岗位、原浏览器页面、正常开发服务或原 Docker 数据卷，不调用付费或本地模型，不登录招聘平台、不发送任何资料。
- Compose 增加 `BETTER_ME_IMAGE` 显式标签覆盖；完整 runtime 与 static 均包含前端入口。运行时验收默认使用随机镜像/项目/端口/测试卷，不覆盖日常镜像标签。没有 USB/ADB、个人 profile、凭据或 Docker socket 挂载，不开 privileged。
