# 履历盘点续片：核对听到的词，精修点选的句子

范围是既有四段式盘点和伴写。没有变更盘点协议、个人画像授权、模型路由或简历写入接口；没有重跑独立的云端五例。上片：[盘点与选材](career-inventory-2026-11-14.md) · [本机按住说话](career-inventory-dictation-2026-11-14.md)。

## 从策略到原句

- 完成盘点并确认后，“重点展开”和“压缩”的经历可展开「选择要精修的原句」。列表取自当前版本、当前语言实际呈现的非空要点，而不是全部底稿中的字符串。点选后，在伴写补充框上方看见原句、本版选材方向，以及这段经历已选用的本人原话。
- 不按单位名、相似措辞或第几项猜测归属。先检查选材时所见的确认回执是否仍是当前账号这份底稿的活动回执，再核对经历组、文档 / 版本 / 指纹、会话与被选中的回答；使用稳定的经历、要点、语言标识和当前字段文字定位。冲突、字段消失或伴写暂停/忙碌时不切换。独立作品、仅有链接或未在本版出现的经历不会挂靠到别的任职；「待补／不选」不进入精修候选。
- 「引用到本轮补充」仅按本人点击追加已确认原话，保留已有补充；它不是确认、生成或采用。跳转不自动调用模型，即使此前打开过本地自动追问。私人偏好不作为补充送入写作；本版选材方向也不是新的事实证据。

## 从转写提示到原词

- 「核对本次转写」下可点否定、数值、部分术语或“可能听错”提示；会聚焦文本框并选中实际候选中的字，不增、删、改字。低置信词只在整段词序能够严格对齐且候选尚未编辑时定位，不向 Host 保存置信度或音频。手动改字后重新定位文字线索；没有提示不保证正确。
- 原有四道边界不变：松手停止收音 → 核对候选 → 点击填入本题 → 另行保存。共识卡的勾选仍独立。

## 五句离线合成样本

macOS Tingting、语速 145、16 kHz 单声道，固定普通话模型 0.22。浏览器实际运行与产品相同的本地解码器。只评事前列出的短语是否保留；忽略标点，接受事先声明的等值数值写法。下表为本轮观察的一次运行，不是用户口音、真实硬件或连续访谈准确率。

| 原创输入 | 识别出的文字 | 预先指定的核对项 |
| --- | --- | --- |
| 我只设计了重试流程，没有上线。 | 我只设计了从事是流程没有上线 | “没有”保留；“重试”丢失 |
| 我不负责部署，只负责接口设计。 | 我不负责部署只负责接口设计 | “不负责”“接口”均保留 |

| 项目在二零二三年三月结束。 | 项目在二零二三年三月结束 | “二零二三年”“三月”均保留 |

这一小组的否定 3/3、数值 4/4、术语 1/3。两处错误附近都有可核对的低置信词，但正确的词也可能被标记；不按置信度猜回“重试”或“Redis”。可用 `node --import tsx apps/agent-host/scripts/verify-inventory-speech-samples.ts` 复验；它只接收五句代码中固定的原创输入，不打开麦克风、不使用账号或云端。

## 验收与边界

体验测试使用隔离账号、合成简历和按次显式同意的模型替身。源码构建后同步相邻源码绑定的 BetterMe.app；脚本以项目 Electron 沙箱加载安装资源，不是对用户日常桌面实例或真实麦克风的验收。

- 网页：同一经历取第二条，亲自引用前补充框为空；模拟回执被替换时留在选材卡，重新读取后才能选择。非选择的私人回答、独立作品和岗位红线都没有出现在该条的补充中。真实下载备份的公开正文投影与导入时一致。普通话按键/指针、可编辑数字的选区、放弃/追加、拒绝/迟到许可分别核验。
- 桌面：对相同的第二句及引用、刷新、导出和岗位提醒单独验证。初次在锁屏状态复验，前台许可不成立，正确拒绝；这次拒绝只算负例。自然解锁后对相同安装资源及安装包自带运行时的正向结果见下文。
- 复验命令：`node --import tsx apps/agent-host/scripts/verify-inventory-ui.ts --installed --dictation`。只验桌面听写加 `--native-only`，只验网页加 `--web-only`；没有 `--dictation` 的桌面运行不覆盖语音。单纯复验不需要重新构建或同步安装资源；桌面端须先由本人正常解锁，不能跳过焦点校验。
