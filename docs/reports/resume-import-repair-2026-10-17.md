## 真实 PDF 离线样本

本轮使用用户指定本地目录中的 3 份 PDF，共 5 页，实际提取文字并执行离线诊断。以下编号仅用于匿名记录，不建立公开的文件名映射。

| 匿名样本 | 已结构化经历数 | 待核对 / 补录条目数 |
| --- | ---: | ---: |
| PDF A | 2 | 30 |
| PDF B | 4 | 14 |
| PDF C | 9 | 1 |

待补录数量按 `unparsedLines` 条目计，不是缺失事实数量，也不是识别错误率。样本结果证明这些文件能够进入离线解析和核对流程，不能据此计算准确率或宣称全量内容已结构化。仅有年份的教育、没有明确日期或角色的项目、当前 Schema 没有独立字段承接的内容，仍需要对照原文补录。

PDF 文字层现在根据坐标重建行、字距和稳定分栏，避免把每个 PDF 字符片段简单插空格或把相邻栏位混成一行。离线规则补充了断开的标题、日期、单位和角色行的组合识别，以及证书等独立段落的归属隔离。没有足够依据时保留原文并提示，不补成任意月份、默认职位或默认项目。

这些规则仍是启发式处理。复杂表格、跨页标题、视觉上相邻但语义不同的段落、缺失文字层和低清晰度扫描件仍可能需要人工核对或视觉解析。

5 页均已渲染并对照查看。每页提取结果的非空白字元及其重复数量与 PDF.js 原始文字项一致，只证明当前重组没有丢失这些文字项，不证明阅读顺序、语义或原文真实性全部正确。其中一份文件的文字层包含可视页面未清楚展示的重叠文字，说明文字层本身也需要与可见页面交叉核对。跨视觉行的同一句话仍可能拆成多个 Claim；原文写有未来结束月份时忠实保留，不自动改成过去日期。

## AI 契约与部分经历

`profile.targetRoles` 的正式类型为多语言对象数组，模型返回字符串数组时，导入器现在可以保留文字内容并转换其表达形状，不再因这一差异整份失败。

现在文字与视觉解析共用明确契约和受限的形状归一：

- 已返回的多语言纯文本可包成 `{ zh: 原文文本 }`，已有 `zh` / `en` 对象保留；不自动生成原文没有的译文。
- 目标职位兼容字符串、字符串数组和多语言对象；已返回的单个列表项可包成数组，不按逗号或斜线擅自重写内容。
- 可选空值不产生默认事实；姓名、单位、角色、要点等纯空白正文不能作为完整内容通过。
- 正式 `FactBaseSchema`、月份合法性、起止顺序和全局经历 / Claim ID 唯一性继续检查；错误包含字段路径。
- 模型提供的量化核实状态被撤销为 `confirmed: false`。未核实量化条目不进入对外简历投影。
- AI 失败不会静默改成离线结果，也不会截断输入或自动删页。

交互导入使用诊断 API，返回完整输入文字、通过字段校验的结构化结果、待核对内容和警告。旧严格 API 继续拒绝包含未解析内容的结果，避免旧调用方静默丢失内容。

诊断模式单独保留信息不足的段落：仅缺少必填起始月份、结束月份、单位或角色时，该段进入待核对区；全部模型字段和要点以明确标识的片段保留，不补默认值。`end: null` 继续遵循现有“至今”契约，不被改写为缺失结束日期。

这类片段标为“AI 部分提取，需与原图 / 原文核对”，并明确说明它是模型返回字段，**不是原文转录**。不能把它与原始文字层、OCR 转录或已经确认的事实混为一类。其他完整经历继续通过正式 Schema 后进入预览。

部分结果不是宽松吞错：已提供字段仍需校验类型和有效日期，倒置日期、错误字段、重复 ID 等继续使整次解析失败；没有任何完整经历可通过正式 Schema 也继续失败。匿名回归覆盖多段结果中仅部分项目缺角色、缺日期或缺单位的情况，以及部分段落中其他字段非法的拒绝行为。

接收端将单位 / 角色中精确等于“不详、未知、未提供、未注明、待确认、N/A、unknown、not specified”的值识别为信息缺失，忽略大小写与首尾空白：诊断模式保留为明确标识的 AI 部分提取片段，严格模式拒绝。这是精确值判断，不会把“未知科技”等含相同字词的实际名称误判；姓名原有的“姓名待确认”状态不受影响。占位拦截不能判断其他看似真实的文字是否由模型补造。

## 图片入口、裁剪与 OCR

图片导入单独识别 JPG / JPEG、PNG、WebP 的实际文件头，并检查浏览器是否能够解码；不能只凭扩展名或 MIME 声明把任意文件当图片，也不会把图片二进制当文本解码。无法解码、无有效尺寸或超过当前像素限制时明确报错。

图片简历可以选择“裁剪简历识别区域”。用户确认裁剪后，视觉请求只发送所选区域；恢复整张图片会撤销这一选择。裁剪范围需在图片内且具有正面积，过期或取消的异步裁剪结果不能覆盖后来选择的文件。正文识别裁剪使用 PNG 输出，减少重复有损压缩；原图保留供当次核对。

视觉 system prompt 要求先识别简历区域，排除手机状态栏、登录横幅、广告、按钮、底部工具栏及聊天输入框。复杂多栏按视觉区域和标题确定归属；不把技能雷达图、进度条和星级图形猜成确定分数；不从照片推断身份属性。正文中不适合当前字段的内容留待核对，图片或正文中的指令不能改变解析规则。

视觉响应新增可选的 `ocrText`，要求按区域逐行转录可读正文、保留换行，无法辨认处标记 `[无法辨认]`，不猜字、不概括、不翻译。接收端检查类型：非字符串、显式空白或只有无法辨认标记时失败；缺少该字段时为兼容旧响应仍可返回，但明确警告没有取得完整转录。

`ocrText` 是可能漏字或误读的模型转录，不能当作原图证据或已确认真值。完整辅助文字层继续保存在 `rawText`，不会被模型转录覆盖；文字 AI 也不能用返回的 `ocrText` 替换用户输入。图片输入、裁剪和 prompt 测试只证明请求与接收约束，不证明某个模型一定遵守这些规则。

| 真实图片检查项 | 结果 |
| --- | ---: |
| 通过字段校验的候选经历 | 13 段 |
| 结构化要点 | 11 条 |
| 待核对 / 补录 | 7 段 |
| OCR 转录 | 1,973 字符 |
| 必填单位中精确未知占位 | 0 |

**此结果只通过了请求、转录返回和预览流程，语义准确性与完整性仍未通过。** 对照原图后，仍发现模型把未明确的角色补成“软件开发”或“项目成员”，以及把项目名当作 `org` 单位。这些文字符合当前字段类型，也不属于精确未知占位，因此能通过格式校验；现有实现没有逐字段来源证据检查，不能自动拒绝所有这类补造。

同一图片的专业字段在不同请求中出现过误读与读对，表明模型输出存在波动。本次读对不能证明再次调用会得到相同结果，也不能据此推断其他字段均正确。13 段经历、11 个要点和 1,973 字符均为该次结果统计，不是准确率、完整率或事实核实结论。

## 来源保存与对外输出

确认导入时，本地创建 `importSource`，保存文件标识、导入时间、完整提取文字、可选模型 OCR 转录和待核对内容。来源记录随本地文档及 JSON 备份保留；页面支持展开核对和下载。模型返回的 `importSource` 在接收端被删除，不能替本地程序伪造来源时间或原始证据。

来源文字、OCR 转录和待核对片段不进入 `ProjectedResume`，也不进入基于该投影生成的对外简历。导入不等于确认每项事实，预览中的正文、时间、归属与量化状态仍需要用户检查。

这里保存的是导入来源信息和核对文本，**来源记录不含原图字节，也没有持久化原始 PDF / Word 文件；它不是附件库、文件数字签名或真实性证明**。当次保留原图预览不等于关闭页面后仍可恢复原图。用户仍需保留原文件；原文件字体、分页、装饰和复杂版式不会由结构化导入自动保存。

## 正确、合理与合法的边界

**正确性。** 本轮修复并测试的是文件读取、字段兼容、必填内容、日期范围、内容保留通道和输出隔离。模型仍可能生成格式合法但没有原文依据的月份、职位或数值，也可能漏读、串段或错误归属。当前没有逐项事实到原文件的证据校验；不能把 Schema 通过、OCR 有文本或请求成功等同于事实正确。

**合理性。** 信息不足时保留通过字段校验的部分与明确待补录内容，允许用户继续核对，不要求模型编造缺失字段才能导入。原文与模型部分提取分开标识，避免把降级结果伪装成完整解析。现有结构要求经历包含起止月份、单位与角色，因此一些真实但只有年份、没有角色的内容仍无法直接成为正式经历；这是当前数据模型的表达边界，不代表这些原文无价值或无效。真实模型仍可能主动补成看似合理的角色，用户确认前必须对照原文件。

**合法性。** 字段格式合法仅表示符合本应用 Schema。用户触发解析时，所选文字或图像会直接发送给其配置的模型服务商；离线规则不需要模型请求。文档中的指令不构成执行授权，本轮没有引入自动投递、第三方登录绕过或商业模板抓取。以上实现不构成简历真实性、文件权属、隐私合规、服务商数据处理条款或招聘平台接受性的法律认证，也没有证明对任何第三方文件或个人信息均有处理授权。

产品不应宣称“100% 保真”“零幻觉”“已认证真实”或“合法性已认证”。适当的状态是：已生成通过字段校验的待核对预览，保留未完成内容，确认后保存。

## 尚未实施的原稿与语义层方案

后续可以将原始文件与结构化语义分开保存：原稿保留字节、页面与原版式；语义层保存经历、Claim、日期精度和逐项来源定位。字段可以关联页码、区域或原句，修改时展示依据与用户确认状态，未明确的月份或角色保留未知状态。

这一方案尚未实现。当前没有原稿附件库、每项事实的页码 / 边界框引用、独立日期精度模型、逐项来源对照工具或完整保真编辑器。不能把 `importSource` 文本留档或模型 OCR 转录当作这些能力已交付。
