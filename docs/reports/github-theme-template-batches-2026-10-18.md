## 本轮新增验证

每个代码批次均从 Git 暂存区通过 `checkout-index` 导出完整源码快照。依赖指向本机已有安装，工作区包指向该快照内部的 core/storage，因此编译和定向测试验证的是该批实际暂存内容，不能由工作区中尚未提交的后续文件补齐缺失依赖。
