# 纸张工作室 UI 与模板视觉升级 · 2026-10-18

用户在前轮研究后明确要求「按上面说的深度优化一版 UI」。本轮据此实施暖白、石墨和森林绿的纸张工作室方向；前轮仅讨论的停点已被本次实施授权替代。

## 交付内容

- 工作台：深绿导航脊柱、清楚的活动态，暖灰画布、乳白面板、白色输入面；统一边缘、圆角、阴影、字级和控件间距。深色采用中性石墨表面，白纸与简历自身配色独立。
- 编辑：提升标签、正文和主要操作的可读性，梳理经历卡片、要点、文字格式栏、保存状态和提示的层次；保存失败、草稿恢复和未核实内容继续保留显著的语义反馈。
- 图库：六套自研模板改用实际 ResumeTemplate 与固定双语合成内容渲染，保持真实 A4 比例；纸页层叠、轻微透视、悬停/键盘聚焦抬升、独立选中标记。缩略图不读取本人 Fact，不产生预览跟随锚点或嵌套链接。
- 纸面：整合重复的模板 CSS，统一参数来源；经典正式采用衬线抬头和细线章节，极简单栏保持顺序文本，现代专业使用结构化抬头，编辑部采用侧标章节，左岸保留资料侧轨，精练履历采用紧凑节奏。
- 预览：明确模板、导出、缩放及显示控制的层级。PDF 保留直接主按钮，DOCX/Markdown/RenderCV 置于菜单；帮助可点击和键盘访问，菜单支持方向键、Home/End、Escape、外部点击与焦点离开。窄屏模板选择独占一行，浮层打开时确保进入可视范围。
- 动效：只在模板切换、卡片关注、浮层出现和按下时反馈；初次挂载、正文输入、保存和缩放不播放纸页入场。快速切换会安全取消前一动画，减少动态偏好关闭这些表现。

## 实现约束与取舍

沿用 Fact → ProjectedResume、稳定 ID、文字格式范围、可见性、草稿、自动保存和历史语义；未改存储、AI、导入、岗位采集或网络架构。前轮已有的工具栏收纳和重复页签移除等未提交改动继续保留。

使用原生 CSS、少量 Web Animations 与既有 React 组件；没有新增 Motion、WebGL 或 3D 运行依赖，没有下载字体或商业模板资产。空间感集中在模板卡片，文字编辑保持稳定。模板继续为自研，没有移植第三方主题。

打印统一由预览的动态 `@page` 使用所选页边距，纸面 padding 在打印时清零，避免重复计算；屏幕纸张仍使用同一页边距作为内边距。连续白纸预览不是逐页分页编辑器；DOCX 继续输出可编辑单栏正文，不承诺与 PDF 同版。

## 验证

最终全量 **1201 / 1201** 通过，fail / cancelled / skipped / todo 全 0；lint、typecheck **5 / 5**、build **3 / 3** 通过。新增保护包括匿名装饰纸页锚点隔离、菜单键盘/外部焦点行为、真实 WAAPI 快速取消、输入/缩放不重播以及减少动态。构建仍有既有的大包提示；最终主 JS 814.39 kB、导入块 852.98 kB、CSS 191.53 kB，没有新增视觉运行依赖。

真实浏览器验收使用独立的 `http://[::1]:5210/` 和匿名内容。中文与英文 UI 下均完成正文编辑、实时预览、手动保存和刷新保持；模板选择、输出语言、照片/ATS、缩放、跟随、历史弹窗以及 MD/DOCX 真实下载分别核对。没有调用 AI 或岗位服务作为视觉验收的一部分。

独立 Headless Edge 的 1440 / 1280 / 768 / 390 px 中文浅色与 1440 / 390 px 英文深色共 6 组最终复验：页面横向溢出 0、导出菜单/帮助裁切或超出屏幕 0、浏览器运行错误 0。实际发现并修复了窄屏操作栏横移、英文新增经历按钮裁切、模板选择器被挤窄、浮层初始缩放导致末端超屏，以及已开菜单的方向键焦点问题。

另有一项未通过的自动化差异：独立 Headless Edge 中，Playwright 的 fill/逐字输入触发带新 DOM 值的可信输入事件后，React 受控 textarea 恢复原值，新上下文可复现；原生值 setter 配合冒泡 input 以及直接 onChange 可更新。实际 IAB 中英文界面的普通输入、保存及刷新保持均通过。尚未定位两者差异，也未证明与本轮 UI 改造存在因果关系；不据此猜测性修改正文逻辑，不将该自动化项计为通过或声称所有浏览器输入均已验收。

实际 PDF 为 **11 组、43 页**，覆盖全部 6 套模板。Classic / ATS / Editorial / Sidebar 包含 12 / 28 mm；另有 Editorial 英文 28 mm、Modern / Compact 中文 16 mm。固定压力样本含 5 段工作、2 个项目、1 段教育和 26 条长要点；全文、52 个起止标记与末尾教育标记完整，工作台 UI 泄漏、实际墨迹越出所选边距均为 0。每页均经 Poppler 渲染并检查，修复了 Chromium 嵌套 Grid 分页造成的孤立抬头和日期分离。结果适用于当前 Windows / Edge 与系统字体，不外推物理打印机或 DOCX 同版，也不视为 ATS 认证。

验收未修改原 `localhost:5173` 用户页面的简历或浏览器存储，未重启原服务；已只读确认该服务在提供新样式入口。验证截图、PDF 与脚本均存本地忽略目录或工作区外的产物目录，没有加入用户数据和 Key，没有提交或推送。
