# 真实岗位的独立城市分布参考

日期：2026-10-19。针对“搜索仍只有腾讯、来源太少”，前批已经修复本机连接恢复及卡片入库后地区核对入口。本批解决另一个展示断点：真实岗位披露了城市但没有可靠办公坐标时，地图没有任何标记。

## 行为与数据边界

连接真实本机索引后，工作台按当前快照只读加载城市参考。已有明确国家及城市、在该国家内可唯一匹配完整地名或真实别名的地点，使用已分发的离线 GeoNames 城市代表点；不从地址文字猜国家、不去掉城市后缀、不选歧义候选第一项。远程资格、冲突地点、已有来源坐标、缺少国家／城市或未命中数据覆盖的地点保留各自原因。

参考点单独存在于查询投影，不写入 SQLite、来源地点或行政决议。岗位本身为完全远程时不绘制办公室式城市参考。原来源坐标优先；原有手动候选查询与明确选择流程保留。城市参考不提供离家距离，即使查询允许其他城市级来源坐标估算也不会使用它。

列表、地图、来源统计及分页使用同一共享查询。城市参考桶与来源坐标桶分开，地图可展示岗位按两类的并集去重；来源坐标岗位、城市参考岗位和待定位岗位分别显示。列表翻页不缩减全量地图。地区、视野及办公室绑定薪资仍要求落在同一个地点，不能拼接不同办公室的字段。

双击有参考的岗位直接飞到城市并高亮，最大 zoom 9。卡片、地图标签与详情均标明城市级估算、非办公地址；详情提供地名数据出处。底图仍可手动继续缩放，缩放不提升岗位地址精度。

## 可复用工具与连接隔离

新增 `locations.map-references`，effect 为 `read-index`，认证接口为 `POST /api/v1/locations/map-references`。输入 `{ expectedRevision, locationIds?, limit? }`，最多 1,000 个地点；输出含版本、完整地点指纹、共享地名出处、参考、未解析原因及实际处理／总地点数。超出范围明确 `truncated`，不宣称未处理地点已定位。`jobs.search` 可通过 `mapCityReferences: true` 复用同一离线工具；纯查询也可接收已验证批次，供 Web 和未来 Agent 共用。

每个参考绑定完整来源地点的 SHA-256 指纹与快照 revision。来源、行政选择、坐标或版本改变会拒绝旧批次；批次也参与分页身份。服务依旧校验认证、预算及取消，不接受客户端指定 provider、文件路径、家庭位置或执行权限。

Web 仅在真实索引连接、页面激活且存在适用地点时读取。连接、快照、视图或激活状态改变会取消旧读取，迟到结果不发布；成功批次只在内存复用，失败不自动反复请求。旧服务 404 明确提示更新／重启，列表仍可使用；支持取消和显式重试。参考退役时清理旧城市桶、定位和相关选中岗位，防止旧城市集合继续限制新列表。
