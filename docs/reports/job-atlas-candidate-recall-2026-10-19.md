# 岗位搜索：召回、部分覆盖与候选核对

日期：2026-10-19。回应用户截图中“三来源返回 102 条、只有一个 C# 岗位”的反馈。102 是来源原始数组及列表记录数，不能视为 102 个符合条件且读全要求的岗位；三个配置公司来源也不能代表四平台或全市场。

## 修复

1. Greenhouse / Ashby / Lever 对已经下载的响应先校验和匹配，再在原输出额度内按 matched → unknown → excluded 分配，最后恢复原站顺序与原数组证据索引。旧实现先取前 20 条，导致后面的相关岗位被漏掉。网络字节、请求、正常分页与输出额度未增加。
2. 腾讯列表取得后的详情 timeout 保留当前页和先前成功的同 ID 详情，标 partial / source-error 并停止余下详情与分页。首次列表失败、取消、限流、权限、预算仍保留错误语义。
3. 进度终态默认收起明细，摘要保留部分、超时和待核对；原始条数、入库数、匹配数分开解释。登记的岗位来源与四平台浏览器搜索的范围写清，逐源实际额度可展开。
4. 待核对候选可显式重新预览当前一页，显示绑定条件、新读取时间、三态分类、原文和纯文本。没有自动重读、翻页、写规范索引或地图。预填机会仅进入人工草稿。切换查询后启动新搜索会关闭旧候选，请求 / 来源 / 连接变化会隔离迟到结果。
5. 四平台 unknown_layout 增加严格固定计数诊断，区分根未找到、隐藏 / 排除 / 不完整移除、链接 / 标题拒绝。诊断不输出页面正文或链接，不放宽原可见性和门禁；此改动本身不代表国内三站已修通。
