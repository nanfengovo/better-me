# 当前简历版本完善与验收 · 2026-10-17

用户要求在成长 Agent 开发前先完善当前版本，并授权本地 Git 提交。本批范围为现有简历工作台的可靠性与使用细节；对话规划、学习、地图、招聘平台、自动投递与插件仍未实施。

## 本批交付

| 范围 | 最终行为 |
|---|---|
| 导入真实性 | 离线规则读取原文真实数值，去掉固定 10% 和默认职位、日期、成果；新解析的数字统一待核实 |
| 导入可核对性 | 展示警告和未结构化行，原文可另存；AI/视觉失败明确报错，完整发送文本和页面，不再静默截断或切换规则 |
| 异步隔离 | 关闭、换文件与重新上传后忽略旧解析/头像结果；头像选择优先于请求开始时的旧状态 |
| 编辑 | 空白新增经历和要点，四种经历类型、英文职位、目标岗位、优势、链接；改动量化正文/数值后撤销原核实 |
| 投影 | 新增经历/要点同步到活动视图；删除清理选择，保留明确隐藏项，空的显式选择不扩大成全部 |
| 保存 | 页面草稿与有效保存状态明确；失败保留旧存储，补齐后自动保存，可下载待修草稿 |
| 恢复 | 损坏数据不被 Demo 覆盖，可下载原始数据；完整备份验证并保存成功后才替换页面，旧读取不覆盖后续编辑 |
| 模板 | Classic、ATS、Modern 独立排版，同源正文；ATS 固定无照片；长内容不由固定高度截断 |
| 打印/导出 | 清除打印祖先容器的双栏、滚动、缩放约束；MD 复制失败有回退提示，文件名过滤非法字符 |
| AI 配置 | 重开回到已保存配置；校验错误/存储失败留窗；模型列表与生成验证区分，生成 90 秒/列表 20 秒超时 |
| JD 报告 | 更换 JD/简历后清空旧报告；忽略过期请求；复制失败可见；兼容服务可不设 Key |
| 提交准备 | 真实个人 SSOT、Key、备份、草稿、缓存和构建产物默认忽略；使用说明与当前实现对齐 |

## 自动检查

- `pnpm test`：40 项回归通过。解析器 16、AI Client 8、投影 5、存储 5、模板静态渲染 6。
- `pnpm lint`：ESLint 实际执行，已替换原占位命令。
- `pnpm typecheck`：核心、存储、Web 类型检查通过。
- `pnpm build`：核心、存储与 Vite 生产构建通过；仍有主包超过 500 kB 的体积建议。
- `pnpm memory:check`：四份开发记忆文件存在性检查通过。

测试模型请求采用 fetch mock，包含超时、错误响应、无效 JSON、不完整 AI 结果、全量长文本/7 页输入及量化状态。存储测试覆盖损坏数据原文保留、配额失败、未完成字段、日期范围与 JSON 往返。模板测试覆盖三种排版的同源内容、照片规则、英文标签、长简历保留、HTML 转义与旧 ID 回退。

## 浏览器检查

在 `http://[::1]:5173/` 使用独立来源下的演示数据检查，与用户原来的 `http://localhost:5173/` 存储分开。

- 选择 Modern 模板，刷新后模板保持。
- 将邮箱改为无效格式，显示未保存提示；修正后自动保存，刷新后邮箱仍存在。
- 新增经历保持空白并提示待补；填写单位/职位/日期后保存，新经历立即进入预览。
- 新增事实要点后输入正文，预览同步。
- 切换 ATS 与英文输出，正文与英文分节正常；70% 缩放下纸张可滚动。
- 保存 Modern 模板截图，包含新增演示经历与对应预览。

## 仍需真实验收的边界

真实云模型生成、用户个人 PDF/DOCX/扫描件 OCR、头像自动识别保真、实际打印 PDF 的跨页效果和招聘系统 ATS 解析未在本批完成端到端验收。打印 CSS 与静态渲染检查不能替代这些真实流程。

离线规则无法结构化的内容保留在诊断中，不会自动纳入事实库；同一句多项数字完整保留在正文，结构化指标目前只取首个可识别值。格式不完整的页面草稿需补齐后才能作为有效备份恢复。

本批不提供 DOCX 导出、AI 建议逐条应用、多份简历管理、自动翻译、学习系统或招聘平台数据接入。项目许可证尚未确定，三套模板为自研布局，未直接移植研究项目。
