## 实现

- `AgentSidebarProvider` 是现有统一 Agent 内核之外的视图层。提供固定 portal 容器，侧栏中切换“伴写对话 / 共识与进度 / 模型与工具”，对话内切换当前经历与自由对话。
- 正式 App 的伴写、Companion、记忆中心、顶部入口均接入同一侧栏。内核旧的打开记忆请求也路由到这里，不叠加三个对话窗口。已有授权/模型配置流程复用，不新增模型通道。
- 简历预览只保留紧凑工具条与纸张区域；Agent 对话不再占据预览的纵向轨道。宽屏（至少 1600 CSS px）侧栏停靠，较窄屏幕使用右侧抽屉，600px 以下全宽抽屉。
- 草稿和请求组件保持挂载；改变页面、侧栏 Tab、收起只改变可见性，不调用停止或改变授权。真正的停止、文档作用域变化和授权失效继续沿用原有安全行为；关闭或重载整个应用不承诺后台继续执行。
- 原文高亮、SVG 虚线与旁批沿用现有锚点。只有纸张与对应旁批同时可见且不重叠时画线；窄屏抽屉中点击原文会先收起再定位，不在遮挡区域画误导性连线。
- 侧栏独立滚动、键盘 Tab 切换、Escape 收起与焦点归还；手机全宽抽屉使背景 inert，并限制键盘焦点在抽屉内。不增加装饰性运动。
- 为不安装该外壳的独立集成保留原组件 fallback，不迁移用户存储或改写自动保存配置。
