# Agent 引导交互增强验收 · 2026-11-02

## 本次范围

在现有 `agent-os`、`f4cc777ba56a937fea970226785bf07875c781c9` 基线上，复用首次工作台引导的聚光定位、可中断动效、跳过和重播模式，增强统一 Agent 侧栏中的八节协作教程。未新增运行依赖，未改真实 Agent 的动态问题生成或授权/写入门禁。

以下首先记录本地实现阶段；随后用户明确授权仅发布本批引导增强、更新 Docker 并跟进 CI。发布范围为本批 17 个产品、测试和文档文件；现有岗位采集改动与三个混合交接文件保留，不纳入提交。实现阶段结果不冒充发布快照或新 SHA 的远端 CI，发布验收另行记录。

## 交互变化

| 原先 | 本次 | 原因 |
| --- | --- | --- |
| 以文字说明为主 | 每节目标、三步操作、预期结果、安全练习与真实入口定位 | 不仅告诉用户有什么，还帮助用户找到下一步 |
| 教程翻页难以反映实际学习 | 阅读和练习分别计数，错误可重试，候选需要演练撤销 | 不把看过教程、模型执行或能力认证混为一谈 |
| 总览指向旧配置入口 | 聚光当前顶部 Agent，交接侧栏并继续上次章节 | 保持现有界面与教学一致，减少重新寻找 |
| 小屏容易被固定内容挤压 | 独立正文滚动、固定退出和翻页，短横屏精简章节栏 | 保证长说明与关键操作都能访问 |

八节依次覆盖资料授权、动态对话、核对共识、认领贡献、旁批候选、历史与备份、模型与工具、超时恢复。固定问题只属于教学示例，支持自由补充的示例不发送；正式对话仍由 Agent 动态生成问题和选项，不限制轮数。

「找到入口」只选择对应视图并提供非模态教练提示；「重新定位入口」才滚动并聚焦。不会替用户展开授权、确认共识、发送请求、采用候选或恢复任务。高亮框按视口与所有滚动祖先裁剪，找不到控件时说明前置条件；切 Tab 移除高亮，保留回到本节的入口。

教程正文使用 220ms 可中断淡入与 8px 轻位移；示例虚线的来源点仅运行两次。键盘操作、关闭动效、隐藏侧栏或系统减少动态效果会取消位移。真实编辑内容与任务不随教程播放装饰动画。现有原文高亮、虚线旁批、采用/撤销保持不变。

## 存储和安全边界

- `betterme.agent-tutorial.v1:<workspaceKey>` 只保存版本、当前章节、已看章节和已练习章节 ID，不存示例输入、简历、对话、授权、凭据、模型或自动保存设置。
- 进度损坏或未知版本回到可用默认值；存储 getter 被禁用、写入失败或额度不足时提示仅本页保留，仍允许练习和退出。
- 隐藏教程、切页、收起或切 Tab 不卸载原工作组件。示例输入是临时教学内容，不承诺作为正式草稿备份；正式任务和草稿保留原有持久化边界。
- 未连接正常 5173 的数据、真实岗位服务、业务目录或真实模型；未自动切换付费 API、重置数据或更改自动保存。

## 实际浏览器验证

使用 CUA 操作独立 `127.0.0.1:5231`，Vite 使用 `tests/ui-lab/resume-layout.config.ts`，不启动后端代理。正式 App 的虚构资料入口 `agent-sidebar-app.html` 与内存确定性夹具 `resume-layout.html?unified=1` 分别验证产品 UI 和延迟任务；不是用户真实资料或真实模型质量验收。

- 逐节访问并练习八节：错误答案不算完成；自由说明仅在示例内；打开候选并撤销后再计入练习。
- 返回工作、重新打开、刷新隔离页后恢复最后章节与 8 节练习记录；原自动保存关闭状态不变。
- 从教程交接到真实授权 summary、理解卡片、备份 summary、阅读工具与任务页，定位只聚焦，未展开授权或自动确认。理解卡片仍为「待你核对」。
- 实测发现已有旁批时仍显示「没有旁批」的误导提示，已改为根据实际命中的入口说明下一步，并增加针对性测试。
- 独立伴写任务运行中打开教程、切章节、收起、切页，再由夹具完成响应，原任务完成且输入草稿保留。此过程未调用真实模型。
- 旧沉浸总览的「你的 Agent」聚光当前 `.agent-top-bar-btn-group`，点击「继续学习 Agent 协作细节」关闭总览、打开侧栏并恢复第 5 节，而非重头开始。
- 浅色与深色均实际检查。实测 CSS 视口 1451×900、389×845、845×389；手机正文约 482px，短横屏正文约 167px 可独立滚动，底部操作下沿约 382px，小于 389px 窗口高度。
- 验收仅操作本轮创建的两个隔离页；原用户浏览器、5173 服务和业务数据不刷新、不关闭、不重启。临时视口覆盖和自建验收服务在结束时清理。
