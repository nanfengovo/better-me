## 修复与边界

- 初始导航：先建立空白自有页面并安装 CDP 观察器，再显式导航。导航命令超时不再立即取消浏览器加载；在限定时间内继续观察真实页面就绪状态。
- 空白恢复：仅自有空白页面无文档响应、无待完成请求时，同一搜索 URL 重试一次，不重置用户页面或登录/验证页。
- 猎聘脚本壳：仅可信搜索页面有加载指示、当前页新增脚本失败、没有登录/验证/限流或 HTTP 错误时，至多同页重载一次。保留此前卡片、去重与进度；永久失败有界退出。
- 脱敏诊断：保存阶段、页面状态、固定路由类别、HTTP 状态、资源失败计数、导航次数和恢复结果。白名单不包含 DOM、页面正文、URL、Cookie、请求头、账户信息或自由文本错误。失败数据请求计数不等于岗位 API 失败计数。
- 后台告警：前台快照已追上目标版本时清除旧快照读取告警；真实 worker/status/读取失败仍保留。
- 来源刷新告警：历史通知失败不能覆盖后续成功快照。所有来源结束后，仍有未被快照覆盖的回执时，只再读一次索引，不重复采集；保留真正来源失败，与仍存在的刷新失败合并显示。
- 实时范围：地区元数据从标签变成代码时，使用地区目录中的明确别名判断查询相等。上海/上海市/Shanghai/CN-SH 等价，但国家、市场、其他城市和不同区县仍不等价。
