## 当前观察

本轮只读查看当前用户工作台与 UI/模板源码。暖白、深绿、纸张感已经形成基础；主要改进空间是容器层级、偏小且碎的文字、说明和控件的注意力分配。需要真实画面比较，不能只从 CSS 推断所有问题。

六套模板有实际结构差异，不能称为纯换色，但仍共享 DOM 与度量系统。模板选择器目前用线条示意，未呈现实际成品；缩略纸张比例也未严格采用 A4。先做同一匿名内容的真实缩略图与放大预览，有明确收益。

## 建议的整体气质

推荐探索“精致的简历工作室”：暖白画布、石墨文字、深绿行动色、实体纸面。用少数有记忆点的交互建立身份，正文编辑保持稳定。

三个候选方向需用同一份内容对照，尚待用户选择：

1. 纸张工作室：温润、细腻、重排版；轻微纸张空间感与精确控件。
2. 精密编辑器：冷白与石墨、更明确的网格、紧凑控制、偏工程工具的清晰感。
3. 空间展台：更强的模板展示和选中反馈，以纸张层叠、柔和光照及连续过渡为记忆点。

建议以第一种为主方向；第三种可作为模板浏览的表现强度参考，但整套材质与动效仍须统一，避免拼装多种设计语言。

## 关键场景建议

- 编辑：固定工作区、层次清楚的输入内容与白纸预览；局部格式工具在需要时出现；保存状态轻量但错误、冲突与风险仍清晰可见。
- 模板库：真实匿名内容、正确纸张比例；悬停/键盘聚焦时轻微抬升与更完整预览，进入编辑后纸张归于正面与静止。
- 换模板：通过纸张与选中标记的连续过渡说明变化；不每次重新播放整页文字入场，也不移动输入焦点。
- 浮层：不透明内容与轻微通透的工具层区分；圆角、阴影、边缘与触感统一。动效表达展开、选择、移动和状态变化，不做常驻漂浮。

优先 CSS 与轻量动效。需要真实光照或空间交互时再评估 3D 渲染，独立按需加载，不使编辑器启动与导出依赖 WebGL。时长、幅度和弹簧参数需在原型中确定，不把初始建议当验收标准。

## 模板排版建议

先精修少量真正不同的排版体系，再扩数量；配色与密度作为各模板内部选项。

| 方向 | 重点 | 应测试内容 |
| --- | --- | --- |
| 中文技术社招 | 公司/职位/日期的扫读层级，成果优先，稳定的单栏与有限强调 | 长公司名、多项目、两页以上、含/无头像 |
| 英文文本投递 | 顺序单栏、清晰链接与日期、弱装饰 | 长英文岗位名、长邮箱、复制/提取顺序；不先承诺 ATS 兼容 |
| 编辑式作品履历 | 侧标章节或适度不对称，姓名与作品的节奏 | 短内容留白与长经历密度，多页延续 |

统一考虑中英文字体搭配、字重、行长、日期对齐、段落节奏、合法字体与跨机换行。中文不机械照搬英文字符间距。SF 等系统资源不直接下载打包；采用可合法使用的字体方案后再评估输出稳定性。

## 保功能与输出边界

- 保留 Fact → ProjectedResume、稳定 ID、文字格式范围、核实与隐藏规则、保存/历史语义，以及编辑跟随所用预览锚点。
- 先对视觉 token、布局与展示组件做隔离改造；不同时重写存储、导入、AI 与岗位逻辑。
- 工作台主题与纸张配色继续独立；键盘、可读对比与减少动态属于质量标准。
- PDF 沿用浏览器打印，必须看实际输出每一页；DOCX 当前是可编辑单栏正文，不保证与网页模板同版。若要求 Word 同款，需单独设计。
- 源码审计发现页面边距的预览 padding 与打印清除 padding/固定 @page 的一致性风险，尚未用实际打印复现，应在视觉施工前核对。
- 短示例、长内容、中英混排、深浅主题、窄屏、空/错误/加载状态与实际 PDF 分页共同验收；既有全绿测试不代替新的视觉与交互验收。

## 建议推进顺序

1. 用同一份匿名内容形成三个有差异的视觉方向，含工作台全貌、真实模板页与一个关键交互。
2. 选定方向后写一页视觉规范与行为清单，统一字号、间距、表面层级、圆角、阴影、色彩与动效规则。
3. 先做一个完整工作台场景与一套模板的隔离预览，再扩展组件和模板。
4. 独立评审以实际画面和操作为依据；先一两轮，反馈指向具体可见问题，不以自评高分当验收。

以上是研究建议，不代表已经实现、安装新视觉依赖或取得用户对某一方向的最终确认。
