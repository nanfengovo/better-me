# Agent icon assets

This directory contains four transparent 3D illustrations generated with the
built-in GPT image-generation tool on 2026-10-28. They are brand-inspired project
artwork, **not official brand logos or endorsements**. The full prompts and tool
provenance are in `generated-prompts.json`.

The reviewed masters were mechanically resized to 256 x 256 transparent WebP
(quality 90, alpha quality 100). All four together are 40,582 bytes. No image API
call occurs at runtime. `*-3d-v1.webp` versioned names allow independent updates.

If artwork cannot load, the UI uses fixed-version Simple Icons brand marks for
providers that have a matching public mark, or an abstract terminal fallback.
The Simple Icons repository is CC0-1.0, but
its README asks users to review the project legal disclaimer and any brand
guidelines before redistribution. Codex and Antigravity use an abstract fallback
because no matching official mark was selected.

Brand names remain visible next to decorative images. Before public distribution,
review applicable trademark guidelines; AI artwork is not a license to a mark.
Do not put API keys or provider connection metadata in this directory.
