BetterMe 模板来源与许可

此镜像提供静态简历工作台。模板使用不同的逐源许可；这些条款不自动覆盖用户填写的事实内容或独立应用模块。本项目整体许可证仍待维护者确定，本页不授予额外权利。

  • 模板说明、授权与功能边界
  • 完整模板目录与逐源 LICENSE / NOTICE 路径
  • 机器可读模板目录
  • 浏览器库及生产依赖的逐包版本、完整 LICENSE / NOTICE
  • 项目源码、原生适配源文件及完整修改说明

所有逐源原文位于本镜像的 /legal/templates/licenses/<source>/LICENSE 与 NOTICE.md；目录中的路径可据此查阅。修改后的模板 CSS 与元数据源文件随镜像保留在 /legal/adapted-source/templates/ 下，使用项目源码中的相同文件名。

依赖许可目录按锁定的 pnpm workspace 生产依赖生成，覆盖应用、core 和 storage 的直接及传递依赖，亦保留未进入静态产物的服务端及可选依赖作为授权超集。nginx 基础镜像自身条款仍分别适用；本页的模板许可不替代它们。此镜像不包含个人简历、API Key、招聘站登录会话或浏览器资料目录。
